# Milestone v1.0: Win Model Improvement

**Status:** ✅ SHIPPED 2026-05-03
**Phases:** 1-4
**Total Plans:** 7

## Overview

単勝モデルのバックテストROIを89%から100%超えに引き上げる。特徴量分析・Benterキャリブレーション・選択ゲート・ウォークフォワード検証の4フェーズで実装。

## Phases

### Phase 1: Feature Analysis & Enhancement

**Goal**: 単勝予測に寄与する特徴量を特定し、ノイズを排除し、単勝特化の新特徴量を追加して、モデル入力の質を最大化する
**Depends on**: Nothing (first phase)
**Plans**: 2 plans

Plans:
- [x] 01-01: SHAP/gain特徴量重要度分析モジュールとノイズ特定・除外
- [x] 01-02: 単勝特化新特徴量6つの実装・統合

### Phase 2: Win Benter Combination & Calibration

**Goal**: 単勝予測に市場効率信号を組み込み、確率を正規化・キャリブレーションすることでEV推定精度を飛躍的に向上させる
**Depends on**: Phase 1
**Plans**: 2 plans

Plans:
- [x] 02-01: WinBenterGate実装・OOF予測生成・レース正規化・パイプライン統合
- [x] 02-02: Beta/Isotonicキャリブレーション比較・ECE評価・信頼性ダイアグラム

### Phase 3: Selection Gate, Confidence & Betting

**Goal**: 学習済みゲートで低信頼レースを除外し、JRA控除率25%を考慮した最適ベッティング戦略を統合する
**Depends on**: Phase 2
**Plans**: 2 plans

Plans:
- [x] 03-01: WinSelectionGate実装・Conformal信頼性拡張・パイプライン統合
- [x] 03-02: JRA控除率考慮edge_threshold更新・ベッティング戦略調整

### Phase 4: Walk-Forward Validation

**Goal**: 複数年度のウォークフォワード検証で過学習を検出し、ROI>100%が単年度の偶然でないことを証明する
**Depends on**: Phase 3
**Plans**: 1 plan

Plans:

## Milestone Summary

**Key Decisions:**
- 2段階モデル(P×E)を維持、改善は精度面で行う
- Benter組み合わせが単勝において最も影響の大きい変更
- Expanding window方式でWF検証(train_years=4, test_years=1)
- JRA控除率25%をedge_thresholdに反映(+0.01)
- WalkForwardCV.generate_folds()非互換のためフォールド定義をハードコード

**Issues Resolved:**
- LightGBM feature_namesはDatasetコンストラクタで設定(lgb.trainには渡せない)
- AbilityModel.models(dict)を反復処理してfeature importance統合(単一model属性なし)
- BacktestEngine状態汚染回避のためtrain/test別インスタンス生成

**Issues Deferred:**
- WF検証スクリプトの実際の実行(PostgreSQL環境必要、~4時間)
- MLflow "wf_validation" 実験結果の確認
- コードレビュー CR-01/CR-02 (既存WalkForwardCVコードの問題)

**Technical Debt Incurred:**
- _add_years_dtの閏年境界オフバイワン(既存コード、WF検証では使用せず)
- np.std ddof=0(既存コード)
