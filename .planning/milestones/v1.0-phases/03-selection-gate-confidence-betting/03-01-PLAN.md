<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Training data -> WinSelectionGate | OOF予測データがgate学習に使用される。データリーク防止はwalk-forward foldで担保 |
| WinSelectionGate -> Bet decision | gateのpass/reject判定がベット可否に直結。gate未学習時はスルー(全pass)の安全なフォールバック |
| RobustConfidenceEstimator -> EV lower bound | CP quantileがEV下限に影響。過小評価は保守的(安全)、過大評価は危険 |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-01 | S (Spoofing) | WinSelectionGate.score() | mitigate | gate未学習時はscore=NaN, pass=Falseで安全にフォールバック。`_trained`フラグで判定 |
| T-03-02 | T (Tampering) | _prepare_training_frame | mitigate | OOF walk-forward foldで学習データとスコアデータの分離を担保。min_fold_races未満はfoldをスキップ |
| T-03-03 | I (Info Disclosure) | WinSelectionGate.save() | accept | モデルファイル(joblib)に機密情報なし。スコアテーブルのみ |
| T-03-04 | D (Denial of Service) | race-condition-dependent CP quantile | mitigate | GroupBy条件でサンプル<30件の場合はglobal quantileにフォールバック |
| T-03-05 | E (Elevation) | ensure_win_selection_columns | mitigate | 列フォールバック連鎖の各段階でNaNを適切に処理。_numeric_or_nanでcoerce |
</threat_model>
