# Milestone v1.1: ROI Advanced Model

**Status:** ✅ SHIPPED 2026-05-03
**Phases:** 5-7
**Total Plans:** 5

## Overview

単勝バックテストROI 100%超えに向けて、アンサンブル・オッズ活用・特徴量改良の3本柱でモデル精度を大幅向上させる

## Phases

### Phase 5: Foundation Features

**Goal**: 過去走の時系列特徴量・展開予測特徴量・オッズ変動特徴量を追加し、後続のモデル改善がより豊かな入力から恩恵を受けられるようにする
**Depends on**: Phase 4 (v1.0 complete)
**Plans**: 2 plans

Plans:
- [x] 05-01: Time-series and pace features (TSER-01, TSER-02, TSER-03, PACE-01, PACE-02)
- [x] 05-02: Odds time-series features (ODTS-01, ODTS-02)

**Details:**
- TSER-01: EMA重み付けハロンタイム(halflife=3)で直近成績を強調
- TSER-02: class_adj_formetric で高クラス好走を高評価する重み付き着順指標
- TSER-03: haron_zscore_trend で過去走z-scoreの線形回帰傾きを定量化
- PACE-01: 3ペースフィグアサブ特徴量(corner_stability, closing_power, position_consistency)
- PACE-02: actual_pace_fit で脚質ベースfront/closing勝率を選択
- ODTS-01: odds_acceleration 3点2次微分でsteam move検出
- ODTS-02: odds_direction_consistency EMA重み付け方向一貫性

### Phase 6: Odds Deviation EV

**Goal**: モデル予測確率と市場オッズの乖離をEV信号としてモデルに直接組み込み、Conformal予測区間でベット選択の信頼性を最適化する
**Depends on**: Phase 5
**Plans**: 1 plan

Plans:
- [x] 06-01: Odds deviation EV features and pipeline integration (ODDS-01, ODDS-02, ODDS-03)

**Details:**
- ODDS-01: compute_odds_deviation_features() でdeviation_rank, deviation_zscoreを生成
- ODDS-02: conformal EV区間(predict_interval)で80%/90% 2レベルalpha信頼区間
- ODDS-03: conformal_confidence_score (EV_lower_80 * (1 - normalized_width_90)) をWinSelectionGate pair scoringに統合

### Phase 7: Ensemble Enhancement

**Goal**: 3モデルスタッキング(LightGBM+XGBoost+CatBoost)の多様性を強制するハイパーパラメータ最適化・early stopping・特徴量サブセット分割を実装し、予測精度を最大化する
**Depends on**: Phase 6
**Plans**: 1 plan

Plans:
- [x] 07-01: Ensemble stacking enhancement with forced diversity (ENS-01, ENS-02, ENS-03)

**Details:**
- ENS-01: Optuna探索空間分離(LGB浅い木31-63/XGB中深さ4-8/CAT深い木6-10)
- ENS-02: K-fold OOF内80/20分割 + early stopping(stopping_rounds=100)
- ENS-03: feature_fraction/colsample_bytree/rsm 0.3-0.9 Optuna最適化

## Milestone Summary

**Key Decisions:**

- Decision: EMA halflife=3 (金融時系列標準) → ✓ Good (TSER-01)
- Decision: 3サブ特徴量分解(単一スコアよりLightGBMが非線形組み合わせ可能) → ✓ Good (PACE-01)
- Decision: conformal_confidence_score = EV_lower_80 * (1 - normalized_width_90) → ✓ Good (ODDS-03)
- Decision: Optuna探索空間分離(各モデルに異なる木複雑度) → ✓ Good (ENS-01)
