# Requirements: keiba-ai v1.3 Betting Strategy Optimization

**Defined:** 2026-05-04
**Archived:** 2026-05-05 (milestone shipped)
**Core Value:** 単勝モデルのバックテストROIを100%超えにすること

## v1.3 Requirements

### Bet Selection (BSEL)

- [x] **BSEL-01**: バックテスト実行時、EV_lower_win_corrected >= 1.0 を満たさないベットが自動除外される — ✅ Phase 11 (Plan 01+02)
- [x] **BSEL-02**: RegimeDetectorがCOLLAPSEDと判定したレースでベットが完全スキップされる — ✅ Phase 11 (Plan 02)
- [x] **BSEL-03**: オッズバンド別ROI分析に基づき、赤字バンドのベットがOddsBandFilterで除外される — ✅ Phase 11 (Plan 01+02)

### Stake Sizing (SIZE)

- [x] **SIZE-01**: レジーム状態に応じたKelly分数が設定される (AGGRESSIVE/CONSERVATIVE/COLLAPSED別) — ✅ Phase 12 (Plan 01+02)
- [x] **SIZE-02**: 高EV機会にEV比例乗算器 (min(ev/target_ev, max_scale)) で重点配分される — ✅ Phase 12 (Plan 01+02)

### Risk Control (RISK)

- [x] **RISK-01**: DrawdownControllerの乗数テーブル・ローリングウィンドウ・リカバリ閾値がWIN向の中率10%に再調整される — ✅ Phase 13 (Plan 01)

### Validation (VAL)

- [x] **VAL-01**: ParameterFreezeProtocolが戦略パラメータをカバーし、ルックアヘッドバイアスを防止する — ✅ Phase 13 (Plan 02)
- [x] **VAL-02**: Optuna TPEで全戦略パラメータの同時最適化が実行され、最適設定が発見される — ✅ Phase 13 (Plan 03)
