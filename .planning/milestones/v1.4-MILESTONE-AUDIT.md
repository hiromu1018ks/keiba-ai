### Integration Warnings

1. **MLflow fallback load path** (`model_loader.py:290-308`): MLflow `load()` メソッドは `SubmodelSet` に `use_ensemble`/`ev_lower_threshold_*` を渡さない。両CLIエントリポイントは `load_from_dir()` を使用するため運用影響なし。影響要件: GATE-03, EVF-01 (MLflowパス使用時のみ)

2. **Engine early return paths** (`engine.py:534-580`): 4つの早期リターンパスが検証レポートを生成しない。データ不足時はバックテスト自体がないため設計上妥当。影響要件: VAL-01 (エッジケースのみ)

### Design Warnings (non-issues)

1. `_compute_ev_threshold` cross-surface fallback: `_train_submodel()` calls per surface, so cross-surface calls produce 0 rows and fall back. No impact — opposite surface thresholds are never used.
2. `_collect_training_bet_history()` accepts but ignores `strategy_params` argument: Intentional for lookahead bias prevention. Interface compatibility only.
3. `StrategyOptimizer._run_single_backtest_with_models()` does not pass `manifest_path`: Correct design — PFP is only needed for final validation in run_backtest.py.
