# Milestone v1.4: Ensemble Filter Recalibration

**Status:** ✅ SHIPPED 2026-05-07
**Phases:** 14-18
**Total Plans:** 10

## Overview

アンサンブルモデルの出力分布にフィルター群を適合させ、年間100+ベット・ROI>100%を達成する。
Phase 14-16でフィルターのアンサンブル適合、Phase 17でパラメータ最適化、Phase 18で検証・固定を完了。

## Phases

### Phase 14: Gate Recalibration

**Goal**: WinSelectionGateがアンサンブルOOF予測で再学習され、quantile binとscore tableが新しい分布に適合し、use_ensembleフラグがパイプライン全体で正しく伝播されている状態になる
**Depends on**: Phase 13 (v1.3 complete)
**Requirements**: GATE-01, GATE-02, GATE-03
**Plans**: 2 plans

Plans:
- [x] 14-01: ドリフト診断モジュール作成 + パイプライン統合 + ゲート再学習検証テスト (GATE-01, GATE-02)
- [x] 14-02: use_ensembleフラグ伝播統合テスト (GATE-03)

**Success Criteria:**
  1. run_backtest.py --ensemble 実行時にWinSelectionGateがアンサンブルOOF予測で再学習され、再計算されたprob_edges/edge_edges/odds_edgesが単一モデルと異なる値になる
  2. ks_2samp/wasserstein_distanceで単一モデルとアンサンブルのOOF確率分布を比較した診断レポートが出力され、ドリフト量が定量化されている
  3. use_ensemble=TrueがModelLoader→RacePredictor→BacktestEngine→WinSelectionGate全経路で一貫して伝播されていることをテストで確認できる

**Requirements**: EVF-01, EVF-02

## Milestone Summary

**Key Decisions:**
- Build order is dependency-ordered: Gate → EV_lower → OddsBand → Optuna → Validation
- EV_lower dynamic threshold: 25th percentile of positive-edge ensemble OOF winners
- Optuna fold count: 4+ (not 2) to prevent overfitting with 14+ free parameters
- Look-ahead bias fix: strategy_optimizer.py must use default params for training_bet_history generation
- PFP dual verification: SHA256 manifest + ParameterFreezeProtocol freeze/verify in BacktestEngine.run()

**Issues Resolved:**
- アンサンブル出力分布とフィルター閾値のミスマッチで年間7ベット/ROI 0% → フィルター再キャリブレーションで解消
- EV_lower固定1.0で3,594件過剰除外 → OOF分布ベース動的閾値で解消
- strategy_optimizer.pyのルックアヘッドバイアス → デフォルトパラメータ使用で解消
- ModelLoader.load_from_dir()のuse_ensemble未伝播バグを検出・修正

**Issues Deferred:**
- VAL-01 partial: ROI>100% + 100+ベットの実際の実行確認 (PostgreSQL環境必要)
- Human UAT 5項目 (全てPostgreSQL依存)
- MLflowフォールバックパスのuse_ensemble未伝播 (運用影響なし)
- Engine早期リターンパス4箇所の検証レポート未生成 (設計上妥当)

**Technical Debt Incurred:**
- 23 ruff lint warnings in test_strategy_optimizer.py (N806 naming, E501 line length)
- Nyquist validation missing for all v1.4 phases
