**1. src/models/ev_diagnostics.py** -- 新規作成:

drift_diagnostics.pyと同じモジュール構造(定数 -> プライベート関数 -> パブリックcompute関数 -> console_summary)で作成。

**モジュール構成:**
- モジュールレベル定数: `EV_PRED_COLUMN = "ev_win_corrected"`, `EV_ACTUAL_COLUMN = "actual_ev_win"`, `EV_LOWER_COLUMN`, `EDGE_COLUMN`, `WIN_COLUMN`, `DATE_COLUMN`, `N_BINS = 10`, `MIN_SAMPLE_SIZE = 30`
- ロガー: `logging.getLogger("models.ev_diagnostics")`
- インポート: json, logging, pathlib.Path, numpy, pandas, scipy.stats.pearsonr, sklearn.calibration.calibration_curve, sklearn.metrics.brier_score_loss

**プライベート関数 (RESEARCH.md Code Examples セクションを参照して実装):**

(a) `_compute_ece(y_true, y_prob, n_bins=10) -> float`:
- RESEARCH.md「ECE Implementation」セクションに完全な実装がある。quantile binning(equal-frequency)を使用。
- `np.percentile(y_prob, np.linspace(0, 100, n_bins + 1))` でビン境界を生成。
- bin_boundaries[0]=-inf, [-1]=inf。
- 各ビンの重み付き絶対差の和: `(n_bin / n_total) * abs(avg_accuracy - avg_confidence)`

(b) `_brier_decomposition(y_true, y_prob, n_bins=10) -> dict`:
- RESEARCH.md「Brier Score Decomposition」セクションに完全な実装がある。Murphy 1973分解。
- 戻り値: `{"brier_score", "reliability" (lower=better), "resolution" (higher=better), "uncertainty"}`
- quantile binningで各ビンの o_k(actual freq) と f_k(predicted freq) を計算。
- reliability = sum(n_k/n * (o_k - f_k)^2), resolution = sum(n_k/n * (o_k - o_bar)^2), uncertainty = o_bar * (1 - o_bar)

(c) `_reliability_diagram_data(y_true, y_prob, n_bins=10) -> dict`:
- RESEARCH.md「Reliability Diagram Data」セクション参照。sklearn.calibration_curve を `strategy="quantile"` で使用。
- 戻り値: `{"fraction_of_positives": list, "mean_predicted_value": list, "n_bins": int}`
- win_benter_gate.py:340 と同じパターン。

(d) `_temporal_drift(df, pred_col, actual_col) -> list[dict]`:
- 年度別(pandas groupby on year)にサンプル数、mean_predicted_ev, mean_actual_ev, ev_bias(=pred-actual), correlation(pearsonr)を計算。
- MIN_SAMPLE_SIZE=30未満の年度は `"warning": "insufficient_samples"` を返す。
- DATE_COLUMN("race_date")がない場合は空リストを返す。

**パブリック関数:**

(e) `compute_ev_diagnostics(df_oof, output_path=None, surface=None) -> dict`:
- actual_ev_win列がなければ `confirmed_odds * (kakuteijyuni==1)` から計算して追加(df_oofをcopyして使用)。
- 有効データ抽出: `pd.to_numeric` で ev_win_corrected と actual_ev_win を取得、notna でマスク。
- MIN_SAMPLE_SIZE未満の場合は早期リターン(warning付き、JSON出力のみ)。
- 上記(1)相関+RMSE (pearsonr, np.sqrt(mean((pred-actual)^2)))、(2)ECE/Brier/Reliability (p_win_corrected列があれば。なければwarning+None)、(3)EV bias (pred_mean - actual_mean)、(4)EV分布統計 (mean/std/q25/q50/q75)、(5)時系列ドリフト を計算。
- output_pathが指定されていればJSON出力。

(f) `console_summary(result) -> None`:
- drift_diagnostics.pyのconsole_summaryパターンに準拠。
- logger.infoで Samples, Correlation, RMSE, EV Bias, ECE, Brier分解, Temporal driftを出力。
- warningがある場合は WARNING 行のみ出力してリターン。
