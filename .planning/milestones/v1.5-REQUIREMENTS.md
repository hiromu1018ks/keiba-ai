# Requirements: keiba-ai v1.5 Model Accuracy Improvement

**Milestone:** v1.5
**Status:** Active
**Created:** 2026-05-07

## Background

v1.4バックテスト (2024年テスト) の結果、ROI 83.1% (投資232,100円/払戻192,870円/利益-39,230円)。
最大の課題はEV推定の2.42倍過大評価 (平均推定EV 2.010 vs 実際ROI 0.831)。

### 根本原因分析

バックテスト診断データ (45,827出走馬) の分析結果:

1. **高オッズ帯(20+)のP過大評価**: 予測P=4.2% vs 実際的中率2.1% → 1.98倍過大
2. **EV上位2五分位の激しい過大評価**: EV>1.5のベットで4.6倍過大評価
3. **高オッズベットが半数を占める**: 20+オッズ帯がベット候補の42% (2,067/4,940)
4. **フィルター不活性**: EV_excluded=0, COLLAPSED_skipped=0 → 全ベットが通過
5. **P×E乗算効果**: PとEの小さな個別バイアスが乗算で増幅

### セグメント別詳細

| オッズバンド | ベット数 | EV過大評価倍率 | P過大評価倍率 |
|-------------|---------|--------------|-------------|
| 1-2         | 11      | 0.87         | 0.75        |
| 2-5         | 179     | 1.10         | 1.04        |
| 5-10        | 848     | 1.13         | 1.11        |
| 10-20       | 1,445   | 1.25         | 1.36        |
| 20+         | 2,067   | **2.08**     | **1.98**    |

## Requirements

### Phase 19: EV推定キャリブレーション

EV過大評価の根本解決。P×E分解の独立性仮定に依存せず、OOF予測ベースでEVを直接キャリブレーションする。

- [ ] **EVC-01**: OOF予測ベースのEV直接キャリブレーション (Isotonic Regression)
  - 入力: ev_win = P×E (補正前)
  - ターゲット: actual_return (1着時=tanodds, それ以外=0)
  - IsotonicRegression で非線形キャリブレーション
  - OOF cross-validationでフィット (データリーク防止)
  - テスト: キャリブレーション前後のECE改善を検証

- [ ] **EVC-02**: オッズバンド別EV補正層の追加
  - キャリブレーション残差をオッズバンド (1-5/5-10/10-20/20+) 別に分析
  - バンド別に補正係数または局所IsotonicRegressionを適用
  - 高オッズ帯の過大評価を重点的に是正
  - テスト: 各バンドのEV過大評価倍率が1.0±0.15に収まることを確認

- [ ] **EVC-03**: EVCorrectionModelへの統合
  - 既存P補正/E補正モデルを置き換えまたは併用
  - TrainingPipelineV5への統合
  - 推論時のキャリブレーション適用
  - テスト: パイプライン統合テスト

### Phase 20: 高オッズ的中パターン特徴量

20+オッズ帯の的中率を2.1%→3%+に引き上げる特徴量エンジニアリング。

- [ ] **HODDS-01**: 高オッズ的中パターン分析モジュール
  - 過去データから高オッズ的中馬 (tanodds >= 20, kakuteijyuni == 1) の共通パターンを抽出
  - 分析軸: クラス変動、着順推移、距離/馬場変更、騎手/調教師変更、休養明け
  - 定性パターンを定量的特徴量候補に変換
  - テスト: 分析結果の再現性テスト

- [ ] **HODDS-02**: クラストラジェクトリ特徴量 (Class Trajectory Features)
  - recent_class_trend: 直近3走のクラスレベル変化傾向 (改善/悪化/安定)
  - class_drop_magnitude: クラス低下の大きさ (降級ボーンス効果の定量化)
  - hidden_class_score: 直近のタイム指标から推定される真のクラスレベル
  - テスト: 特徴量生成の単体テスト + 欠損値処理

- [ ] **HODDS-03**: フォーム改善率特徴量 (Form Improvement Features)
  - finish_position_trend: 直近着順の傾向 (線形回帰スロープ)
  - speed_figure_trend: タイム指标の改善傾向
  - recent_improvement_flag: 直近2走で着順が大幅改善したフラグ
  - テスト: 特徴量生成の単体テスト

- [ ] **HODDS-04**: 環境変化適性特徴量 (Context Switch Features)
  - distance_switch_wr: 距離変更時の過去勝率
  - surface_switch_wr: 馬場変更時の過去勝率
  - trainer_change_flag: 転厩フラグ + 転厼後初戦勝率
  - jockey_upgrade_flag: 騎手ランク向上フラグ
  - テスト: 特徴量生成の単体テスト

- [ ] **HODDS-05**: 新特徴量のAbilityModel/WinTwoStageModelへの統合
  - FEATURE_COLSへの追加
  - FeatureEngine.compute_batch()への統合
  - Feature importance分析での効果確認
  - テスト: パイプライン統合テスト

### Phase 21: Conformal EV予測区間

EV推定の不確実性を定量化し、信頼区間に基づくベット選択を実現。

- [ ] **CONF-01**: Conformal Prediction EV区間実装
  - 非適合度スコア: |ev_calibrated - actual_return|
  - CQR (Conformal Quantized Regression) ベースの予測区間
  - alpha=0.1 (90%信頼区間) と alpha=0.2 (80%信頼区間) の2レベル
  - OOFデータでキャリブレーション
  - テスト: カバレッジ率が1-alpha以上であることを検証

- [ ] **CONF-02**: EV信頼区間ベースの動的フィルタリング
  - EV_lower_bound = ev_calibrated - conformal_margin
  - ベット条件: EV_lower_bound > 1.0 (従来のev > ev_threshold を置き換え)
  - 予測区間幅によるconfidence_score計算
  - テスト: フィルタリング条件の単体テスト

- [ ] **CONF-03**: ConformalEVのパイプライン統合
  - BacktestEngineでのEV_lower_bound適用
  - 既存EV_lowerとの互換性確保
  - 診断レポートへの区間情報追加
  - テスト: バックテストパイプライン統合テスト

### Phase 22: 統合検証とバックテスト

- [ ] **VAL-01**: 全改善適用後のバックテスト実行
  - 学習期間: 2020-2024、テスト期間: 2024
  - ROI改善確認 (目標: 95%以上)
  - セグメント別 (オッズバンド/芝ダート/レジーム) のROI分析
  - テスト: バックテスト結果の妥当性検証

- [ ] **VAL-02**: EVキャリブレーション品質検証
  - キャリブレーション後のECE改善確認
  - EV過大評価倍率のセグメント別確認
  - 信頼区間のカバレッジ率確認
  - テスト: 診断メトリクスの妥当性検証

## Success Criteria

1. **ROI改善**: バックテストROIが83.1%から95%以上に改善
2. **EV精度**: EV過大評価倍率が全セグメントで1.0±0.2に収束
3. **高オッズ帯ROI**: 20+オッズ帯のROIが50%以上に改善 (現状23.6%)
4. **フィルター活性化**: EV_excluded > 0 となるベットが存在
5. **テスト**: 全新規コードにテストあり、既存テスト全通過

## Dependencies

- Phase 19 (EV Calibration) → Phase 21 (Conformal) → Phase 22 (Validation)
- Phase 20 (Features) → Phase 22 (Validation)
- Phase 19 と Phase 20 は並行開発可能
