**変更A: P2 Categorical変換 (D-04) -- ParquetStore.read()に最適化を追加**

`src/db/parquet_store.py`に以下を追加:

```python
# モジュールレベル定数
CATEGORICAL_COLUMNS: frozenset[str] = frozenset({
    "race_id", "kettonum", "kisyucode", "chokyosicode",
    "sire_id", "bms_id", "umaban",
})


def _optimize_dtypes(df: pd.DataFrame) -> pd.DataFrame:
    """高カーディナリティ文字列列をpd.Categoricalに変換 (P2: D-04)"""
    for col in CATEGORICAL_COLUMNS & set(df.columns):
        if df[col].dtype == object:
            df[col] = df[col].astype("category")
    return df
```

そして`read()`メソッドの全return文で`_optimize_dtypes(df)`を適用する。`read()`には4つのreturn文がある:
- 行47: `return table.to_pandas()` → `return _optimize_dtypes(table.to_pandas())`
- 行52: `return self._apply_filters(df, filters)` → `return _optimize_dtypes(self._apply_filters(df, filters))`
- 行54: `return pd.read_parquet(...)` → `return _optimize_dtypes(pd.read_parquet(...))`
- 行57: `return self._apply_filters(df, filters)` → `return _optimize_dtypes(self._apply_filters(df, filters))`
