## Overview

芝モデルのIC改善と投資判断パイプライン再構築。上がりタイム/ラップタイムETL基盤構築、芝レース相対特徴量強化、MarketModel配線修正、OOF健全性検査基盤、投資判断用統合特徴量フレームを構築した。BT ROIはv1.7 97.8%から87.8%に低下（Phase 36強特徴量の副作用）、投資パイプライン基盤は完成。

## Milestone Summary

**Decimal Phases:**
- Phase 36.1: HaronTime L4/LapTime Redesign (inserted after Phase 36 for data source fix + cross-level features)

- Benter-type market blend: logit(p_model) + logit(p_market) for strong market prior
- Segment Calibration integration (Option B): WSC as MarketAwareWinCalibrator feature, not standalone model
- Deployment criteria = probability quality: Brier/logloss/ECE/actual-pred, not ROI
- Regime-independent + bet count reduction prohibited
- Phase36 features kept but surgically routed per model role (fundamental models keep, market models exclude)
- OOF health as fail-fast validation at save point (producer-side)
- InvestmentFeatureSpec frozen dataclass for compile-time schema safety
