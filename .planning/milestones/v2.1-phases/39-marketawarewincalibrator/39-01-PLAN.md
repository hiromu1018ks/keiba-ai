Methods:

1. build_feature_matrix(df) -> tuple[np.ndarray, list[str]]:
   - Input df MUST have columns: p_model, p_market, tanodds, popularity_rank, field_size, p_win_race_rank_pct
   - Compute logit(p_model) = log(p_model / (1 - p_model)) with eps=1e-10 clipping
   - Compute logit(p_market) similarly
   - Compute log_odds = log1p(tanodds) (D-08 continuous)
   - Compute popularity_rank_pct = popularity_rank / field_size clipped [0,1] (D-12)
   - p_win_race_rank_pct used as-is (D-14)
   - field_size as-is (additional main effect for context)
   - One-hot encode odds_band via pd.cut(tanodds, bins=ODDS_BAND_EDGES, labels=ODDS_BAND_NAMES, right=False) then pd.get_dummies -- ensure all 7 columns present (D-11)
   - One-hot encode popularity_bucket via pd.cut(popularity_rank, bins=POP_BUCKET_EDGES, labels=POP_BUCKET_NAMES) -- ensure all 5 columns present (D-11)
   - One-hot encode p_rank_bucket: top 25% = p_win_race_rank_pct >= 0.75, mid 25-75% = 0.25 <= pct < 0.75, bottom 25% = pct < 0.25 -- ensure all 3 columns (D-11/D-15)
   - Interactions: logit_model[:, None] * segment_features + logit_market[:, None] * segment_features (D-06, 30 dims)
   - Final: 6 main effects + 15 one-hot + 30 interactions = 51 features (D-17)
   - Return (X, feature_names)

2. train(df, n_splits=5):
   - Guard: if "p_win_pred" in df.columns and "p_win_oof" not in df.columns, raise ValueError (D-22)
   - Extract y = (kakuteijyuni == 1).astype(int)
   - Build feature matrix via build_feature_matrix
   - Extract race_ids and race_dates for WF splits
   - Reuse _walk_forward_race_splits pattern from win_benter_gate.py for chronological WF splits on race_id/race_date
   - C-selection grid search (D-04): for each C in C_GRID, fit LogisticRegression(C=C, max_iter=1000, fit_intercept=True) on each WF train fold, predict on val fold, compute log_loss. Primary metric: mean logloss. Secondary: Brier. Tie-breaker: smaller C (D-04).
   - Year/surface actual/predicted ratio gate (D-05): after C-selection, for each candidate C compute actual/predicted ratio grouped by year and by surface. Reject any C where year-level or surface-level ratio worsens materially (>10% relative degradation vs overall ratio). If no C passes all gates, set _trained=False and record as shadow-only in training_summary.
   - beta_market guard (D-03): after selecting best_c, fit final model on all data with best_c. Inspect coef_ at index corresponding to logit(p_market) column.    - Return df with p_win_combined, p_win_final, edge_win columns
