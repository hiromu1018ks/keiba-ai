    Method `_align_race_level(results: dict[str, BacktestResult]) -> pd.DataFrame`:
    - Convert each variant's bet_history to DataFrame.
    - For each race_id in the union of all variants' races, extract: the selected umaban (the horse that was bet on), closing_win_odds, tanodds, p_win_final, e_return_win_corrected, win_selection_ev, win_market_selection_score, investment_score, result, final_odds, stake.

    Method `_align_horse_level(results: dict[str, BacktestResult]) -> pd.DataFrame`:
    - For each variant, the bet_history already contains per-horse diagnostic rows. Merge by race_id + umaban across variants.
    - Produce columns: baseline_p_win_final, shadow_p_win_final, baseline_investment_score, shadow_investment_score, baseline_selected (bool), shadow_selected (bool), and other diagnostic columns from bet_history.

    Method `compute_metrics(aligned_race: pd.DataFrame, aligned_horse: pd.DataFrame, variant_name: str, bet_history: list[dict]) -> ComparisonMetrics`:
    - ROI: sum(return) / sum(stake) - 1 from bet_history filtered to this variant's bets.
    - HR: winning_bets / total_bets.
    - Bet count: len(bet_history).
    - Avg odds: mean of closing_win_odds across bets.
    - Max DD: from BacktestResult.max_drawdown.
    - Brier: mean((p_win_final - is_win)^2) across all horse-level rows where p_win_final exists. is_win = 1 if result == 1 else 0.
    - Logloss: mean(-is_win * log(p_win_final) - (1-is_win) * log(1-p_win_final)).
    - ECE: Expected Calibration Error. Bin predictions into 10 equal-width bins. ECE = sum(|avg_predicted - avg_actual| * bin_count / total) across bins.
    - CLV: closing_odds / betting_odds - 1 where both exist and are valid (> 0). Report mean CLV across bets. Set clv=None, clv_available=False if fewer than 10% of bets have valid CLV inputs.
    - Selection agreement: fraction of races in aligned_race where selected_changed == False. Computed from the alignment DataFrame, not per-variant.
    - Avg investment_score: mean of investment_score across horse-level rows for this variant where the value exists. None if column absent.
    - Actual/predicted ratio: mean(actual_is_win) / mean(p_win_final) across all horse-level rows.

    Method `compute_metrics_by_group(aligned_horse: pd.DataFrame, group_col: str) -> dict[str, ComparisonMetrics]`:
    - Group aligned_horse by group_col (e.g., "surface", "odds_band", "prob_rank_band") and compute ComparisonMetrics for each group using the same logic.
    - odds_band: derived from closing_win_odds bins [1-3, 3-5, 5-10, 10-30, 30+].
    - prob_rank_band: derived from selected_rank_by_p_win_final bins [1, 2, 3, 4-6, 7+].
    - surface: from horse-level data if available, else from race metadata.

    Method `run(folds: list[FoldDefinition] | None = None) -> list[ShadowComparisonResult]`:
    - Default folds = FoldDefinition.create_folds([2024, 2025]).
    - Call run_fold for each fold, return list of results.
