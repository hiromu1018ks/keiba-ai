    Create `scripts/run_shadow_comparison.py` per D-07:

    **CLI arguments using argparse:**
    - `--baseline-root` (Path, required): Root directory containing baseline model year subdirectories (e.g., data/models-backtest/)
    - `--shadow-root` (Path, required): Root directory containing shadow model year subdirectories
    - `--folds` (list[int], nargs="+", default=[2024, 2025]): Fold years to run
    - `--train-window` (int, default=4): Training window in years
    - `--betting-target` (str, default="win"): Betting target
    - `--output-dir` (Path, default=Path("data/backtest/shadow")): Output directory
    - `--report` (flag): Generate HTML report
    - `--baseline-name` (str, default="baseline"): Name for baseline variant
    - `--shadow-name` (str, default="ridge_shadow"): Name for shadow variant
    - `--betting-mode` (str, default="flat"): Betting mode (flat/kelly)

    **Main logic:**
    1. Parse args.
    2. Build VariantConfig list:
       - Baseline: variant_name=baseline_name, model_dir=baseline_root, enable_market_aware_calibrator=False, enable_race_level_ranker=False (per D-18)
       - Shadow: variant_name=shadow_name, model_dir=shadow_root, enable_market_aware_calibrator=True, enable_race_level_ranker=True
    3. Build folds: FoldDefinition.create_folds(args.folds, train_window=args.train_window)
    4. Create ShadowComparisonFramework(variants, betting_target=args.betting_target, betting_mode=args.betting_mode)
    5. Run: results = framework.run(folds)
    6. Save artifacts: artifact_paths = ShadowComparisonFramework.save_results(results, args.output_dir)
    7. Save manifest: ShadowComparisonFramework.save_manifest(results, variant_configs, args.output_dir, artifact_paths)
    8. If --report: generate HTML report via ShadowComparisonReportGenerator
    9. Print summary to stdout: fold-by-fold ROI comparison, selection agreement, key metric deltas

    **Output printing format:**
    ```
    Shadow Comparison Complete
    =========================
    Fold 2024:
      Baseline: ROI=87.8%, HR=12.3%, Bets=1234
      Shadow:   ROI=95.2%, HR=13.1%, Bets=1198
      Delta ROI: +7.4pp | Selection Agreement: 87.3%
    Fold 2025:
      ...
    =========================
    Overall: Baseline ROI=87.8% -> Shadow ROI=95.2% (+7.4pp)
    Artifacts saved to: data/backtest/shadow/
    ```
