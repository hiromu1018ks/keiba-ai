2. Define CalibratorArtifactProfile as a regular class (NOT frozen dataclass -- it has behavior methods) with:
   - __init__ with configurable parameters: required_columns (default tuple with race_id, p_win_combined, p_win_final, fold), forbidden_columns (default ("p_win_pred",)), probability_columns (default tuple with p_win_combined, p_win_final), fold_col (default "ability_oof_fold"), sum_to_one_tolerance (default 1e-6)
   - validate(self, df: pd.DataFrame) -> list[str] method that returns failure strings. Per D-07:
     a. Check required_columns all present in df.columns. Missing -> failure for each.
     b. Check forbidden_columns NOT present in df.columns. Present -> failure for each.
     c. Check fold_col present in df.columns. Missing -> failure.
     d. For each probability_column: check no NaN (failure if any), check no inf (failure if any), check all values in [0, 1] range (failure if any outside).
     e. Check sum-to-1.0 per race_id: group by race_id, sum probability_columns[0] (p_win_combined), check abs(sum - 1.0) < tolerance. Failure if violated.
     f. Return list of failure strings.

3. Define RankerArtifactProfile as a regular class with:
   - __init__ with: required_columns (default tuple with race_id, investment_score, fold), score_columns (default tuple with investment_score, relevance_score, value_score), fold_col (default "ability_oof_fold")
   - validate(self, df: pd.DataFrame) -> list[str] method. Per D-08:
     a. Check required_columns present. Missing -> failure.
     b. Check fold_col present. Missing -> failure.
     c. For each score_column: check no NaN (failure if any), check no inf (failure if any).
     d. Check race-level rank determinism: for each race_id, if investment_score exists, rank horses by investment_score within race. If two horses have identical investment_score but get different ranks (due to pandas method="first" vs "min"), that is a warning, not a failure. Collect warnings separately and append to failures with "WARNING: " prefix.
     e. Return list of failure strings.

4. Module-level instances for convenience:
