   - Decision criteria: status must be "PASS"
   - What it checks: OOF-01 through OOF-08 (empty, overlap, top1 anomaly, row coverage, fold count, multi-fold races, required columns)
   - Expected runtime: < 1 second

   - Full command: `python scripts/run_shadow_comparison.py --baseline-root data/models-backtest --shadow-root data/models-backtest-mawc-conservative --folds 2024 2025 --output-dir data/backtest/shadow_mawc_conservative --baseline-name baseline --shadow-name mawc_conservative --report`
   - Decision criteria: shadow_comparison_result.json created successfully
   - Expected runtime: ~82 minutes (2 years)
   - Troubleshooting: if --shadow-name is wrong (Pitfall 1), variant names in downstream diagnosis will be incorrect. Verify variant_names in shadow_manifest.json.

   - CLI: `python scripts/run_shadow_diagnosis.py --input-dir data/backtest/shadow_mawc_conservative --output-dir data/backtest/shadow_mawc_conservative/diagnosis --report`
   - Function API alternative: `python -c "from backtest.shadow_diagnosis import ShadowDiagnosis, save_diagnosis_results; from pathlib import Path; sd = ShadowDiagnosis(Path('data/backtest/shadow_mawc_conservative')); r = sd.run(); save_diagnosis_results(r, Path('data/backtest/shadow_mawc_conservative/diagnosis'))"`
   - Decision criteria: diagnosis runs without error
   - Expected runtime: seconds

8. **Stage 2 Step 5: DeploymentGateEvaluator**
   - Function API: `python -c "from backtest.deployment_gates import run_deployment_gates; r = run_deployment_gates('data/backtest/shadow_mawc_conservative/shadow_comparison_result.json', 'data/backtest/shadow_mawc_conservative/shadow_manifest.json', 'data/backtest/shadow_mawc_conservative/gates'); print(r.overall_status)"`
   - Decision criteria: overall_status must be "PASS" (not "FAIL" or "WARN")
   - Important note (Pitfall 4): diagnostic_oof_health and diagnostic_feature_routing_audit gates are always SKIP. These do NOT indicate OOF/audit passed. Verify Steps 1 and 2 independently.
   - Expected runtime: < 1 second

   - Expected runtime: ~90 minutes total (Stage 1 ~10 min + Stage 2 ~82 min)

    - Pitfall 5: OOFHealthValidator has no CLI -- use function API
