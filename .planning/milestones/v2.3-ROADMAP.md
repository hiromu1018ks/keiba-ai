## Milestone Summary

**Key Decisions:**
- D-04: entry_id(18-digit) = race_id(first 16) + umaban(last 2) (47-01)
- D-10: load_track_conditions follows existing load_* pattern with exists-check gate (47-02)
- 外科的ルーティング: 6 included / 4 excluded models (48-01)
- D-10: turf_cushion_track_relative uses training-period-only trackcd-level mean (no lookahead) (48-01)
- PIT-safe expanding window + shift(1) for horse aptitude (49-01)
- Linear interpolation bias/kickback scores with NaN propagation (49-02)
- Surface-aware NaN verification with 3-tier verdict (50-01)
- Post-hoc EV threshold optimization: 1.40 → 124.4% ROI (50-02)

**Issues Resolved:**
- 含水率・クッション値CSVのエントリ単位→race_level集約パイプライン構築
- 芝/ダートのNaN-safe設計によるcross-surface特徴量の安全な計算
- track_month_statsのパイプライン統合(track_statsと同様にSubmodelSet保存)
- 5つのNaN FAIL特徴量の原因分離(raw data不足 vs derived processing)

**Issues Deferred:**
- IC評価レポート生成(OOF予測が必要、別途run_train.py実行)
- 4 RACE_CONDITION特徴量の100% NaN修正(track_month_stats利用可能性問題)
- sire_x_cushion_bandの51.63% NaN改善(種牡馬×クッション交差データ不足)
- WF検証スクリプトの実際の実行(~4時間、PostgreSQL環境必要)
- Human UAT 5項目 (PostgreSQL依存)

**Technical Debt Incurred:**
- RACE_CONDITION特徴量4つが実質不活性(100% NaN)。構造修正はv2.4+で検討
- IC評価はスクリプト+テストのみ完了。実際のOOFデータでの評価は次回学習時
- test_training_pipeline.py 3件既知失敗(RecordFeatures.compute mock問題)
