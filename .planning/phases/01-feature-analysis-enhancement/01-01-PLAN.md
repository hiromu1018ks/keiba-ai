## Trust Boundaries

|----------|-------------|
| trained model -> analysis script | Model file loaded from filesystem. Corrupted model could cause unexpected behavior. |
| analysis output -> FEATURE_COLS | --auto-exclude flag can modify FEATURE_COLS. Without flag, human reviews report before removing features. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-01 | Tampering | analyze_feature_importance.py model loading | accept | Script runs locally, model files are user-controlled. No network exposure. |
| T-01-02 | Information disclosure | feature importance CSV output | accept | Output contains no PII, only model metadata. Local filesystem only. |
| T-01-03 | Tampering | remove_noise_features() modifying FEATURE_COLS | mitigate | validate_noise_removal() compares logloss/AUC before and after removal. Warns if degradation exceeds 0.5%. |
