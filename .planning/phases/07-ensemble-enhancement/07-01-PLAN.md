    ```python
    def _tune_hyperparams(self, X_train: pd.DataFrame, y_train: pd.Series, num_threads: int) -> dict[str, dict[str, Any]]:
        """Optunaで各モデルのHPを個別最適化 (D-01, D-02, D-03)"""
        import optuna
        optuna.logging.set_verbosity(optuna.logging.WARNING)

        n = len(X_train)
        split = int(n * 0.8)
        X_t, y_t = X_train.iloc[:split], y_train.iloc[:split]
        X_v, y_v = X_train.iloc[split:], y_train.iloc[split:]

        best_params = {}
        for model_name, suggest_fn, train_fn in [
            ("lgbm", self._suggest_lgbm_params, self._eval_lgbm),
            ("xgb", self._suggest_xgb_params, self._eval_xgb),
            ("cat", self._suggest_cat_params, self._eval_cat),
        ]:
            study = optuna.create_study(direction="maximize")
            study.optimize(
                lambda trial, fn=suggest_fn, tf=train_fn: tf(trial, fn, X_t, y_t, X_v, y_v, num_threads),
                n_trials=30,
            )
            best_params[model_name] = study.best_params
        return best_params
    ```

    ### StackedEnsemble._check_diversity() の追加 (D-09, D-10, D-11):

    ```python
    def _check_diversity(
        self,
        oof_preds: np.ndarray,
        y_train: pd.Series,
        importances: list[np.ndarray],
        feature_names: list[str],
    ) -> None:
        """OOF予測の多様性を検証 (D-09, D-10, D-11)"""
        import logging
        from scipy.stats import spearmanr

        logger = logging.getLogger(__name__)
        model_names = ["LGB", "XGB", "CAT"]

        # ペアワイズ相関 (D-09)
        corr_matrix = np.corrcoef(oof_preds.T)
        pairs = [(0, 1, "LGB-XGB"), (0, 2, "LGB-CAT"), (1, 2, "XGB-CAT")]
        for i, j, name in pairs:
            c = corr_matrix[i, j]
            logger.info("OOF prediction correlation %s: %.4f", name, c)
            if c >= 0.95:
                logger.warning(
                    "High prediction correlation %s: %.4f >= 0.95 — diversity may be insufficient",
                    name, c,
                )

        # Feature importance Spearman順位相関 (D-10)
        for i, j, name in pairs:
            rho, _ = spearmanr(importances[i], importances[j])
            logger.info("Feature importance rank correlation %s: %.4f", name, rho)
            if rho > 0.8:
                logger.warning(
                    "High importance correlation %s: %.4f > 0.8 — models rely on similar features",
                    name, rho,
                )
    ```

    ### StackedEnsemble._compute_importance() の追加:
    各ベースモデルのfeature importanceを抽出するヘルパーメソッド。
    - LightGBM: model.feature_importance(importance_type="gain") を返す
    - XGBoost: model.get_score(importance_type="gain") をDataFrame化して全特徴量分の配列を返す
    - CatBoost: model.get_feature_importance() を返す
    戻り値: list[np.ndarray] — [lgb_importance, xgb_importance, cat_importance]

    ### StackedEnsemble.train() への統合:
    K-fold OOFループ完了後、Ridge学習前に_check_diversityを呼び出す:
    ```python
    # after K-fold OOF loop, before Ridge
    valid_mask = ~np.any(np.isnan(oof_preds), axis=1)
    # extract feature names
    feature_names = list(X_train.columns)
    # compute importances from final models (use first fold models as proxy,
    # or compute after full models are trained)
    importances = self._compute_importance(feature_names)
    self._check_diversity(
        oof_preds[valid_mask],
        y_train.iloc[valid_mask] if hasattr(y_train, 'iloc') else y_train[valid_mask],
        importances,
        feature_names,
    )
    ```
    注意: _check_diversityはfinal modelが学習された後に呼び出す(importancesをfinal modelから取得するため)。よって、Ridge学習後、final model学習後の位置に配置する。Ridge自体はOOF予測に基づくので、final model学習前で問題ない。順序は: (1) K-fold OOF → (2) Ridge (OOF基準) → (3) Final models → (4) _check_diversity(final model基準)。

    実際の配置順序:
    1. K-fold OOF ループ
    2. Ridge メタラーナー学習 (OOF基準)
    3. Final models 学習 (train+valid全データ)
    4. _check_diversity 呼び出し (final modelのimportance + OOF予測相関)
