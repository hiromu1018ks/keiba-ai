(2b) generate_validation_report(
    result: BacktestResult,
    test_start: str,
    test_end: str,
    train_start: str,
    train_end: str,
    manifest_path: Path | None = None,
    pfp_result: dict[str, Any] | None = None,
) -> dict[str, Any]:

RESEARCH Pattern 2のJSON schemaを実装。戻り値dictの構造:
```python
{
    "validation_timestamp": ISO8601文字列,
    "test_period": [test_start, test_end],
    "train_period": [train_start, train_end],
    "manifest": {
        "path": str(manifest_path) or None,
        "sha256_verified": True/False/None,
        "sha256_hash": str or None,
    },
    "pfp_verification": pfp_result or {"passed": None, "message": "PFP not used"},
    "roi": {
        "total_roi": result.total_roi,
        "total_bets": result.total_bets,
        "total_stake": result.total_stake,
        "total_return": result.total_return,
        "target_roi": 1.0,
        "target_bets": 100,
        "passed": result.total_roi > 1.0 and result.total_bets >= 100,
    },
    "yearly_breakdown": {  # bet_historyのrace_dateから年別集計
        "2024": {"roi": ..., "bets": ..., "stake": ..., "return": ...},
    },
    "validation_result": "PASS" or "FAIL",
    "cause_analysis": None or generate_cause_analysis()の結果,  # ROI<100%時のみ
}
```

manifest.sha256_verifiedはmanifest_pathがあればTrue(verify済み前提)、NoneならNone。
yearly_breakdownはbet_historyのrace_date[:4]で年別に集計。
total_roi <= 1.0の場合のみgenerate_cause_analysis()を呼び出してcause_analysisに設定する(D-11)。

(2c) generate_cause_analysis(bet_history: list[dict[str, Any]]) -> dict[str, Any]:

RESEARCH Pattern 3を実装。以下の分析項目を含む:

- odds_band_roi: オッズバンド別ROI。オッズはb.get("final_odds", b.get("odds", 0))を使用。
  バンド: 1.0-2.0, 2.0-5.0, 5.0-10.0, 10.0+。各バンドのroi, bets, stake, returnを集計。
- regime_roi: レジーム別ROI。b.get("regime", "UNKNOWN")でグループ化。
- ev_diagnosis: EV過大/過小評価分析。ev>=1.0をoverestimated、ev<1.0をunderestimatedに分類。各グループのcount, avg_ev, actual_roiを集計。
- bet_count_sufficiency: {total, target: 100, sufficient: bool}
- surface_roi: 芝/ダート別ROI。b.get("surface", "unknown")でグループ化。

全てのbet_historyフィールドアクセスは.get()で防御する(Pitfall 4回避)。
空bet_historyの場合は{"error": "No bet_history available"}を返す。
