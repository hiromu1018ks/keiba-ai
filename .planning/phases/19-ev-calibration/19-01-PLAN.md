**2. OOF EV生成関数を実装** (src/pipelines/training_pipeline.py):

`TrainingPipelineV5` クラス内に新しいstatic method `generate_ev_oof_predictions()` を追加する。この関数は_train_submodel()から呼び出される。

```python
@staticmethod
def generate_ev_oof_predictions(
    df: pd.DataFrame,
    *,
    n_splits: int = 5,
    num_threads: int = 0,
) -> tuple[np.ndarray, np.ndarray, np.ndarray]:
    """EVC-01/D-05/D-09: OOF EV予測をK-foldで生成.

    学習チェーン: AbilityModel OOF → WinTwoStage predict_ev → EVCorrection correct_ev
    Returns: (oof_ev_corrected, oof_actual_return, oof_odds) — NaN-masked arrays
    """
```

実装パターンは `src/models/win_benter_gate.py:108-146` (generate_win_oof_predictions) と同じK-foldパターン:
- `df.sort_values("race_date").reset_index(drop=True)` で時系列ソート
- `KFold(n_splits=n_splits, shuffle=False)` — shuffle=False必須 (look-ahead bias防止)
- 各foldで:
  1. `fold_win = WinTwoStageModel()` をインスタンス化
  2. `fold_win.train_hit_model(df.iloc[train_idx], num_threads=num_threads)`
  3. `fold_win.train_return_model(df.iloc[train_idx], num_threads=num_threads)`
  4. `fold_val = fold_win.predict_ev(df.iloc[val_idx].copy())`
  5. `fold_ev_corr = EVCorrectionModel()`
  6. `fold_ev_corr.train(fold_val, num_threads=num_threads)` — 必要な特徴量がfold_valに含まれている前提
  7. `fold_val = fold_ev_corr.correct_ev(fold_val)`
  8. `oof_ev_corrected[val_idx] = fold_val["ev_win_corrected"].values`
  9. `oof_actual_return[val_idx] = (fold_val["confirmed_odds"] * (fold_val["kakuteijyuni"] == 1).astype(float)).values` — confirmed_oddsがなければodds列を使用
  10. `oof_odds[val_idx] = fold_val.get("confirmed_odds", fold_val.get("odds", 0)).values`

関数の戻り値は3つのnp.ndarray: `oof_ev_corrected, oof_actual_return, oof_odds`

**重要**: fold内でAbilityModel OOFを再生成する必要はない。df_oofには既にAbilityModel.train_oof()由来のp_ability_winが含まれている。各foldではWinTwoStage + EVCorrectionのみを再学習する。

```python
@staticmethod
def fit_ev_calibration(
    oof_ev: np.ndarray,
    oof_actual: np.ndarray,
    oof_odds: np.ndarray,
) -> tuple[IsotonicRegression, dict[str, float]]:
    """EVC-01/EVC-02: OOF EV→actual_returnのIsotonicキャリブレーション + オッズバンド別残差スケーリング.

    Returns: (isotonic_model, odds_band_scales)
    """
```

実装:
1. valid mask: `valid = np.isfinite(oof_ev) & np.isfinite(oof_actual) & (oof_ev > 0)`
2. Isotonic fit (D-01/D-03/D-04):
   ```python
   from sklearn.isotonic import IsotonicRegression
   iso = IsotonicRegression(y_min=0, out_of_bounds="clip")
   iso.fit(oof_ev[valid], oof_actual[valid])
   ```
3. Isotonic transform でOOF EVをキャリブレーション:
   ```python
   ev_calibrated = np.copy(oof_ev)
   ev_calibrated[valid] = iso.transform(oof_ev[valid])
   ```
4. オッズバンド別残差スケーリング (D-10, Pattern 3 from RESEARCH):
   ```python
   from betting.odds_band_filter import OddsBandFilter
   BANDS = OddsBandFilter.BANDS
   BAND_NAMES = OddsBandFilter.BAND_NAMES
   MIN_SAMPLES = 50

   band_scales: dict[str, float] = {}
   for band_name, (lo, hi) in zip(BAND_NAMES, BANDS):
       mask = (oof_odds >= lo) & (oof_odds < hi) & valid
       if mask.sum() >= MIN_SAMPLES:
           residual_ratio = oof_actual[mask] / np.clip(ev_calibrated[mask], 1e-6, None)
           band_scales[band_name] = float(np.median(residual_ratio))
       else:
           band_scales[band_name] = 1.0
   ```
5. 戻り値: `(iso, band_scales)`

```python
        df["ev_win_corrected"] = df["p_win_corrected"] * df["e_return_win_corrected"]

        # --- Phase 19: Isotonic EV Calibration (D-08) ---
        if self.ev_isotonic_calibrator is not None:
            ev_input = df["ev_win_corrected"].values.astype(float)
            valid = np.isfinite(ev_input)
            calibrated = np.copy(ev_input)
            if valid.any():
                calibrated[valid] = self.ev_isotonic_calibrator.transform(ev_input[valid])
            df["ev_win_calibrated"] = calibrated
        else:
            df["ev_win_calibrated"] = df["ev_win_corrected"].copy()

        # --- Phase 19: Odds Band Residual Scaling (D-10) ---
        if self.ev_odds_band_scales is not None:
            odds_col = "confirmed_odds" if "confirmed_odds" in df.columns else "odds"
            if odds_col in df.columns:
                odds = pd.to_numeric(df[odds_col], errors="coerce").values.astype(float)
                calibrated = df["ev_win_calibrated"].values.astype(float)
                from betting.odds_band_filter import OddsBandFilter
                for (lo, hi), band_name in zip(OddsBandFilter.BANDS, OddsBandFilter.BAND_NAMES):
                    scale = self.ev_odds_band_scales.get(band_name, 1.0)
                    if abs(scale - 1.0) < 1e-9:
                        continue
                    mask = (odds >= lo) & (odds < hi) & np.isfinite(odds)
                    calibrated[mask] *= scale
                df["ev_win_calibrated"] = calibrated

        df = df.drop(columns=["_p_win_corrected_raw"], errors="ignore")
        return df
```

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
