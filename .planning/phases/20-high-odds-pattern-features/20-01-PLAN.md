**Function 1: compute_class_trajectory**

```python
def compute_class_trajectory(
    gradecd_arr: np.ndarray,
    jyokencd1_arr: np.ndarray,
) -> tuple[float, float, float, float, float, float, float]:
```

ロジック (per D-05, D-06, D-07):
1. 各要素について `_class_level_from_values(gradecd_arr[i], jyokencd1_arr[i])` を呼び出して数値レベルに変換。ローカルに `_CLASS_LEVEL_MAP = {"A": 8.0, "B": 7.0, "C": 6.0, "D": 5.0, "E": 4.0}` を定義し、`_class_level_from_values` と同じロジックをインライン化 (horse_history_features.py からのインポートは循環参照を避けるためコピー)。
2. NaN値を除外。有効要素 < 2の場合は全て NaN を返す。
3. 差分配列 `np.diff(levels)` を計算:
   - `class_promotions` = `(diffs > 0).sum()` (昇級回数)
   - `class_demotions` = `(diffs < 0).sum()` (降級回数)
   - `class_net_change` = `levels[-1] - levels[0]` (ネット変化)
   - `class_max_level` = `levels.max()` (最高クラス到達)
   - `class_level_std` = `levels.std()` (クラス分散)
4. V字回復検出 (per D-07):
   - `v_recovery_flag = 0.0`, `v_recovery_duration = NaN`
   - levels配列を走査し、降級 (`diffs[i] < 0`) を検出した後、その降級位置以降に再昇級 (`diffs[j] > 0`) がある場合
   - 最初の降級位置から最初の再昇級位置までの走数（インデックス差）を `v_recovery_duration` に設定
   - `v_recovery_flag = 1.0`
   - 複数回の降級→再昇級があっても最初の1回のみを記録
   - 注意: 既存の `class_drop_bounce` (直近1走のみの降級バウンス) とは異なり、複数走にわたるバウンスを捉える (per CONTEXT.md D-07)

**Function 2: compute_form_improvement_rate**

```python
def compute_form_improvement_rate(
    zscore_arr: np.ndarray,
    kakuteijyuni_arr: np.ndarray,
    syussotosu_arr: np.ndarray,
    halflife: int = 3,
) -> tuple[float, float]:
```

ロジック (per D-08, D-09):
1. NaN値を除外。有効要素 < 2の場合は両方 NaN を返す。
2. EMA重み付けを計算 (per horse_history_features.py L714-723 の確立パターン):
   ```python
   decay = np.log(2) / halflife  # ≈ 0.231
   n = len(valid_arr)
   weights = (1 - decay) ** np.arange(n)
   weights = weights[::-1]  # index 0 = newest (highest weight)
   weights = weights / weights.sum()
   ```
3. **time_improvement_rate:** z-score配列は低いほど良いタイム。改善率 = EMA重み付け平均が全体平均より低いかどうか:
   - EMA平均と全体平均の差を全体の標準偏差で正規化: `(overall_mean - ema_mean) / overall_std`
   - 正の値 = 直近改善（EMAが全体より低い = 最近良いタイム）
   - `overall_std == 0` の場合は `0.0`
4. **position_improvement_rate:** 着順を正規化 `(pos-1)/(size-1)` して同じ計算:
   - 正規化着順配列を計算: `norm_pos = (kakuteijyuni - 1) / np.maximum(syussotosu - 1, 1)`
   - EMA重み付けで直近の改善度を測定。正の値 = 直近改善
   - 注意: form_trend (form_cycle_features.py、線形回帰傾き) とは意図的に直交させる。form_trendは線形、improvement_rateはEMA指数重み付け (per RESEARCH.md Anti-Patterns)
