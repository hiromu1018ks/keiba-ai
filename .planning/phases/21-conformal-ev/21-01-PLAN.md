    **1. src/models/conformal_ev_model.py を新規作成:**

    ConformalEVModel クラスを実装。以下の仕様に従う:

    ```python
    class ConformalEVModel:
        """CQR (Conformalized Quantile Regression) によるEV予測区間推定.

        Romano et al., 2019 "Conformalized Quantile Regression" に基づく。
        LightGBM quantile regression で分位点を学習し、CQR非適合スコアでCP補正する。
        """
    ```

    **__init__(self, alpha: float = 0.1, feature_cols: list[str] | None = None):**
    - `self.alpha = alpha` (0.1 = 90%区間)
    - `self.feature_cols = feature_cols`
    - `self._calibrated = False`
    - `self.q_low_model: lgb.Booster | None = None`
    - `self.q_high_model: lgb.Booster | None = None`
    - `self._calibration_quantile_90: float = 0.0` (alpha=0.1用)
    - `self._calibration_quantile_80: float = 0.0` (alpha=0.2用)

    **train(self, df_calib: pd.DataFrame, *, num_threads: int = 0, lgb_params: dict | None = None) -> None:**
    - CQRの学習 + キャリブレーションを実行する。
    - 引数 `df_calib` は以下の列を含む: `ev_win_calibrated`, `actual_ev_win`, `feature_cols`で指定された特徴量列
    - 手順:
      1. `feature_cols`がNoneの場合、df_calibから`ev_win_calibrated`, `actual_ev_win`, `confirmed_odds`, `kakuteijyuni`, `race_id`, `umaban`, `surface`, `race_date`, `EV_lower_win_corrected`, `EV_upper_win_corrected`, `conformal_confidence_score`, `ev_place_corrected`, `actual_ev_place`などの非特徴量列を除外して特徴量を自動抽出
      2. バリデーション分割: df_calibをrace_dateでソート済み前提で、前80%をtrain、後20%をcalibに分割。既に外側で分割済みの場合は、引数で`train_ratio=1.0`に設定可能にする（デフォルト0.8）
      3. df_trainから`X_train = df_train[feature_cols]`, `y_train = df_train["ev_win_calibrated"]`を抽出。NaN行を除外
      4. LightGBM quantileモデルを2つ学習:
         - `q_low_model`: paramsに`{"objective": "quantile", "alpha": alpha/2, ...}`を設定。例: alpha=0.1ならquantile=0.05
         - `q_high_model`: paramsに`{"objective": "quantile", "alpha": 1 - alpha/2, ...}`を設定。例: alpha=0.1ならquantile=0.95
         - 基本params: `{"objective": "quantile", "metric": "quantile", "learning_rate": 0.05, "num_leaves": 31, "min_child_samples": 20, "verbose": -1}`。lgb_paramsが渡された場合は上書き
         - `lgb.train(params, train_set, num_boost_round=200, valid_sets=[train_set], callbacks=[lgb.log_evaluation(0)])`
      5. df_calibにq_low, q_highを予測: `q_low_pred = q_low_model.predict(X_calib)`, `q_high_pred = q_high_model.predict(X_calib)`
      6. CQR非適合スコア: `E = np.maximum(q_low_pred - y_calib, y_calib - q_high_pred)`
      7. 90%補正量子: `n = len(E)`, `Q_90 = np.quantile(E, min((1 - 0.1) * (1 + 1/n), 1.0))`
      8. 80%補正量子: `Q_80 = np.quantile(E, min((1 - 0.2) * (1 + 1/n), 1.0))`
      9. `self._calibration_quantile_90 = Q_90`, `self._calibration_quantile_80 = Q_80`
      10. `self._calibrated = True`
    - サンプル不足時(200未満)はwarningを出してreturn（フォールバックはpredict_interval側で処理）

    **predict_interval(self, win_df: pd.DataFrame, place_df: pd.DataFrame, alphas: tuple[float, ...] = (0.1, 0.2)) -> tuple[pd.DataFrame, pd.DataFrame]:**
    - RobustConfidenceEstimator.predict_interval()と同じシグネチャ・出力互換 (per D-06)
    - 手順:
      1. win_df, place_df を copy()
      2. 未キャリブレーション時のフォールバック: `ev_win_calibrated`列があればその値を`EV_lower_win_corrected`/`EV_upper_win_corrected`に設定、なければ0.0。`conformal_confidence_score = 0.0`。placeも同様
      3. ev_win_calibratedをベースEVとして取得: `win_ev = pd.to_numeric(win_df["ev_win_calibrated"], errors="coerce").fillna(0.0)`。列がなければ`ev_win_corrected`をフォールバック
      4. CQR予測: `q_low = self.q_low_model.predict(X_win)`, `q_high = self.q_high_model.predict(X_win)`
      5. モノトonicity保証: `q_low = np.minimum(q_low, q_high)` (q_low <= q_highを保証)
      6. 90%区間(第一alpha): `lower_90 = np.maximum(q_low - self._calibration_quantile_90, 0.0)`, `upper_90 = q_high + self._calibration_quantile_90`
      7. 80%区間(第二alpha): `lower_80 = np.maximum(q_low - self._calibration_quantile_80, 0.0)`
      8. 出力:
         - `win_df["EV_lower_win_corrected"] = lower_90` (90%区間下限 per D-04)
         - `win_df["EV_upper_win_corrected"] = upper_90` (90%区間上限)
      9. conformal_confidence_score計算 (RobustConfidenceEstimatorと同じロジック):
         - `interval_width = (upper_90 - lower_90).clip(lower=1e-6)`
         - `max_width = interval_width.groupby(win_df["race_id"]).transform("max").clip(lower=1e-6)` (race_idがない場合は全体max)
         - `normalized_width = (interval_width / max_width).clip(0.0, 1.0)`
         - `win_df["conformal_confidence_score"] = (lower_80 * (1.0 - normalized_width)).fillna(0.0)`
      10. Place側は簡易処理: `place_ev = ev_place_corrected`, `EV_lower_place = place_ev`, `EV_upper_place = place_ev` (CQR適用なし、既存のplaceモデルは別対応)
    - Returns: `(win_df, place_df)`

    **save(self, models_dir: Path, surface: str) -> None:**
    - q_low_model, q_high_modelを`{models_dir}/cqr_quantile_low_{surface}.lgb`, `{models_dir}/cqr_quantile_high_{surface}.lgb`に保存
    - キャリブレーションパラメータを`{models_dir}/cqr_params_{surface}.json`に保存: `{"alpha": self.alpha, "calibration_quantile_90": ..., "calibration_quantile_80": ..., "feature_cols": ..., "_calibrated": True}`
    - `_calibrated=False`の場合は保存しない（warning log出力）

    **load(cls, models_dir: Path, surface: str) -> "ConformalEVModel | None":**
    - クラスメソッド。3つのファイル(low.lgb, high.lgb, params.json)が揃っていればロード
    - ファイルが揃っていなければNoneを返す
