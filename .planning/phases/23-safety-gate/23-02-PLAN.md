win_feature_analysis.py にsklearn permutation_importanceベースの計算関数を追加 (per D-06, D-08)。

1. ファイル先頭のimportに以下を追加:
   - `from sklearn.inspection import permutation_importance`
   - `from sklearn.metrics import make_scorer, log_loss, mean_absolute_error, roc_auc_score`

2. 新規関数 `compute_permutation_importance` を追加:
   - シグネチャ: `def compute_permutation_importance(model: lgb.Booster, features_df: pd.DataFrame, y: np.ndarray, *, n_repeats: int = 5, random_state: int = 42, max_samples: int = 5000, scoring: str = "auto") -> pd.DataFrame:`
   - `scoring="auto"` の場合、yの値分布を確認して自動選択: yが {0,1} のみ → `"neg_log_loss"`, それ以外 → `"neg_mean_absolute_error"`。ただしauto選択の代わりに呼び出し元で明示的に指定することも可能。
   - sklearn互換のpredict function wrapper を定義: `def predict_fn(X): return model.predict(X)` — 引数Xはndarray/DataFrame、戻り値はndarray。
   - サブサンプリング: `len(features_df) > max_samples` の場合、`np.random.default_rng(random_state).choice()` でインデックスを抽出。
   - `permutation_importance(predict_fn, X_sample, y_sample, n_repeats=n_repeats, random_state=random_state, scoring=scoring_str)` を呼び出し。
   - 戻り値: DataFrame columns `["feature", "perm_importance_mean", "perm_importance_std"]` — feature列は `model.feature_name()` から取得。

3. 新規関数 `compute_all_model_importance` を追加:
   - シグネチャ: `def compute_all_model_importance(models: dict[str, lgb.Booster], features_df: pd.DataFrame, targets: dict[str, np.ndarray], *, n_repeats: int = 5, random_state: int = 42, max_samples: int = 5000) -> tuple[pd.DataFrame, dict[str, Any]]:`
   - 引数 `models`: モデル名→Boosterのdict (例: `{"stage1": booster, "win_hit": booster, ...}`)。
   - 引数 `targets`: モデル名→ターゲット配列のdict。
   - 各モデルに対してgain importance (`model.feature_importance(importance_type="gain")`) とpermutation importanceの両方を計算。
   - 戻り値: (pivot_df, metadata_dict)
     - pivot_df: CSV出力用。columns = `["feature", "<model1>_gain", "<model1>_perm", "<model2>_gain", "<model2>_perm", ...]`
     - metadata_dict: JSON出力用。`{"models": {model_name: {"gain": {...}, "perm_mean": {...}, "perm_std": {...}}}, "metadata": {"n_samples": N, "n_repeats": 5, "timestamp": "..."}}`

4. 既存の `analyze_feature_importance` と `identify_noise_features` は変更しない (後方互換)。

analyze_feature_importance.py CLIを全モデル対応に拡張 (per D-06, D-07, D-08)。

1. argparse引数を追加:
   - `--all-models` (action="store_true"): 全モデルの重要度を一括計算
   - `--model` (choices=["stage1", "win_hit", "win_return", "place_hit", "place_return", "ev_correction", "place_ev_correction"]): 単一モデル指定
   - `--format` (choices=["csv", "json", "both"], default="both"): 出力形式
   - `--n-repeats` (int, default=5): permutation importance試行回数
   - `--output-json` (str, default="feature_importance_report.json"): JSON出力パス

2. `_find_model_file` を汎用化:
   - 引数 `model_name` (例: "win_hit", "stage1") と `surface` を受け取る。
   - model_name="stage1"の場合は `ability_*.lgb` パターンで検索。
   - model_name="win_hit"の場合は `win_hit_*.lgb` (既存ロジック)。
   - model_name="win_return"の場合は `win_return_*.lgb`。
   - model_name="ev_correction"の場合は `ev_p_correction_*.lgb` または `ev_e_correction_*.lgb` (P補正モデルを使用)。
   - model_nameが指定されない場合のデフォルトは "win_hit" (後方互換)。

3. `_load_features_for_analysis` を拡張:
   - モデルのfeature_name()に対応する列のみを抽出する (既存ロジック)。
   - ターゲット列(kakuteijyuni等)も返すよう拡張: 戻り値を `(features_df, target_series)` のタプルにする。後方互換のため既存コードも動作するようにする。

4. main() に `--all-models` ロジックを追加:
   - model_dir内の全モデルファイルをglobで検索 (`*.lgb` パターン)。
   - ファイル名からモデル名とsurfaceを推定 (例: `win_hit_turf.lgb` → model_name="win_hit", surface="turf")。
   - 各モデルのBoosterを読み込み、`models` dict と `targets` dict を構築。
   - ターゲット: binaryモデル(hit系)は `kakuteijyuni`→{0,1}変換、regressionモデル(return系)は `confirmed_odds` または `e_return_win_pred` を使用。ターゲット列がない場合はダミー生成してpermutationをスキップしgainのみ計算。
   - `compute_all_model_importance(models, features_df, targets)` を呼び出し。

5. 出力セクションを拡張:
   - `--format csv` または `--format both`: pivot_dfをCSV保存 (`--output` パス)。
   - `--format json` または `--format both`: metadata_dictをJSON保存 (`--output-json` パス)。`json.dump` でインデント付き出力。np.float64等のnumpy型は `float()` でPython型に変換してからdump。
   - `--format both` (デフォルト) の場合、両方出力。

6. 既存の `--model-dir` 単体指定時の動作 (win_hitモデル分析) は維持する (後方互換)。
