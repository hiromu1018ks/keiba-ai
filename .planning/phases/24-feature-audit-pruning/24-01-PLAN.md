    win_feature_analysis.py に classify_feature_tiers() 関数を追加する。

    関数シグネチャ: classify_feature_tiers(pivot_df: pd.DataFrame, metadata: dict[str, Any], *, tier2_percentile: float = 10.0) -> dict[str, dict[str, Any]]

    引数:
    - pivot_df: compute_all_model_importance() の戻り値 (columns: feature, {model}_gain, {model}_perm, ...)
    - metadata: compute_all_model_importance() の戻り値
    - tier2_percentile: Tier 2の下位パーセンタイル閾値 (デフォルト10.0)

    戻り値: {model_name: {"tier1": [feature_names], "tier2": [feature_names], "tier1_count": int, "tier2_count": int}}

    Tier 1判定 (D-01): Gain == 0 AND Perm <= 0。permutation importanceがNaNのモデル（return/E-correction）では Gain == 0 のみで判定。
    Tier 2判定 (Claude's discretion): Tier 1に含まれず、gain値が当該モデル内で下位 tier2_percentile% に位置する特徴量。gain > 0 のみ対象（Tier 1と重複しない）。

    実装詳細:
    - metadata["models"] を反復して各モデルのtier分類を実行
    - 各モデルのgain値を取得（metadata["models"][model_name]["gain"]）
    - perm_mean値を取得（NaN考慮）
    - Tier 1: gain == 0 AND (perm_mean <= 0 OR perm_mean is NaN)
    - Tier 2: gain > 0 AND gain <= np.percentile(nonzero_gains, tier2_percentile)
    - タイムスタンプ付きlogger.info で各モデルのTier 1/2件数を出力

    テスト追加 (tests/test_win_feature_analysis.py):
    - TestClassifyFeatureTiers クラスを追加
    - test_tier1_identifies_gain_zero_perm_negative: Gain=0 AND Perm<=0 をTier 1とするテスト
    - test_tier1_nan_perm_uses_gain_only: Perm NaNの場合 Gain=0 のみでTier 1判定
    - test_tier2_identifies_low_gain_percentile: Tier 2が下位10%を正しく特定するテスト
    - test_no_overlap_between_tiers: Tier 1とTier 2に重複がないことを確認
    - test_returns_per_model_structure: 戻り値がモデル別dict構造であることを確認
  </action>
