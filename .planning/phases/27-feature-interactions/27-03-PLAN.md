    クラス TargetEncoder:
    __init__(cat_cols: list[str], target_col: str = "kakuteijyuni", n_folds: int = 3, smoothing: int = 10, min_samples: int = 5):
    - cat_cols: TE対象のカテゴリ列名リスト
    - target_col: ターゲット変数名。kakuteijyuni を使用 (1着==1, それ以外==0)
    - n_folds: OOF fold数。AbilityModel.train_oof()と同じ3
    - smoothing: Beta(1,10)パターンの平滑化パラメータ (jockey_context_features.py参照)
    - min_samples: カテゴリ別最小サンプル数。これ未満の場合グローバルmeanに近い値になる

    fit_transform_oof(df: pd.DataFrame) -> pd.DataFrame:
    - dfはrace_date列を含むこと (ソート不要、内部でソートする)
    - dfをrace_dateでソート
    - target_binary = (df[target_col] == 1).astype(int) を計算
    - AbilityModel.train_oof()と同一のfold境界を計算:
      dates = sorted(df["race_date"].unique())
      boundaries = [dates[n_dates * (i+1) // (n_folds+1)] for i in range(n_folds)]
    - 各foldについて:
      train_mask = df["race_date"] < boundaries[i]
      test_end = boundaries[i+1] if i+1 < n_folds else dates[-1] + 1day
      test_mask = (df["race_date"] >= boundaries[i]) & (df["race_date"] < test_end)
      train_df, test_df に分割
      各cat_colについて:
        cat_stats = train_df.groupby(cat_col)[target_binary].agg(["sum", "count"])
        cat_mean = (cat_stats["sum"] + smoothing * global_mean) / (cat_stats["count"] + smoothing)
        -- smoothingロジック: (sum + smoothing * global_mean) / (count + smoothing)
        -- min_samples未満のカテゴリはsmoothingが強く効く -> global_meanに近い値
        test_dfのcat_colをcat_meanにマップ
        未マップ (未知カテゴリ) はglobal_meanで補完
    - 全foldのTE値を結合して返す
    - self.encoding_maps_ に各cat_colの{category: te_value}を保存 (transform用)
    - self.global_mean_ を保存

    transform(df: pd.DataFrame) -> pd.DataFrame:
    - fit_transform_oof()で保存したencoding_maps_を使用してTE値をマップ
    - 未知カテゴリはglobal_mean_で補完
    - 新規データ (推論時) に使用

    _compute_fold_global_mean(train_target_series: pd.Series) -> float:
    - trainデータの全体target meanを計算
