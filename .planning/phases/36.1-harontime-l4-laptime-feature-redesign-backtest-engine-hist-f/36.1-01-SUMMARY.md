### D-07: harontime_last3f L3-only unification
- DISTANCE_THRESHOLD constant removed
- harontime_last3f_avg/zscore/trend always computed from harontimel3 only
- No L4 fallback for any distance range

### D-08: harontimel4_avg/zscore/trend replaced by closing_speed_ratio
- BASE_COLS: `harontimel4_avg/zscore/trend` replaced by `closing_speed_ratio_avg/zscore/trend`
- Results dict keys updated
- `add_race_transforms` race_rank_cols updated
- `race_predictor._race_rank_cols` updated

### D-01: closing_speed_ratio = L3/L4 (3 features)
- `closing_speed_ratio_avg`: EMA(halflife=3) weighted average
- `closing_speed_ratio_zscore`: PIT-safe via expanding_stats_csr with FALLBACK_LEVELS
- `closing_speed_ratio_trend`: Linear regression slope of last 3 values
- Computed only when both L3 and L4 are valid (NaN otherwise, LightGBM handles)

### D-02: haron_race_gap = L3 - L4*0.75 (3 features)
- `haron_race_gap_avg/zscore/trend`: Same EMA/zscore/trend pattern
- Scale factor 0.75 = 3F/4F physical ratio
- Negative = fast closing kick (strong)

### D-03: pace_adj_finish_avg = norm_finish * pace_ratio (1 feature)
- Combines individual finishing position with race pace context
- Uses existing `_pace_lookup` for pace_ratio, date-matched to past race entries
