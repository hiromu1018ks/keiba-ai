# Phase 36.1.1 Plan 02: Race-Level Phase36 Aggregates + Quality Score Fix Summary

RaceQualityScreener に 5 つの Phase36 race-level aggregate 特徴量を追加し、build_race_features()と_build_race_level_features()の両パスで計算。BacktestEngine の quality_score=0.0 固定問題を predict_score()/get_quality_score() で解決。

## What Changed

### RaceQualityScreener.FEATURE_COLS (40 columns, +5)

| Feature | Source | Aggregation |
|---------|--------|-------------|
| `phase36_top1_strength` | closing_speed_ratio_avg | max() per race |
| `phase36_top1_top2_gap` | closing_speed_ratio_avg | nlargest(2) diff |
| `phase36_field_dispersion` | closing_speed_ratio_avg | std() per race |
| `phase36_form_signal_dispersion` | form_trend_race_rank | std() per race |
| `phase36_weighted_form_mean` | weighted_recent_form_finish | mean() per race |

### New Methods

| Class | Method | Returns |
|-------|--------|---------|
| `RaceQualityScreener` | `predict_score(race_features: dict)` | float |
| `RacePredictor` | `get_quality_score(race_df: pd.DataFrame)` | float |

### New Helper

| Module | Function | Purpose |
|--------|----------|---------|
| `race_predictor.py` | `_compute_phase36_aggregates(race_df)` | NaN-safe race-level aggregation from horse-level Phase36 columns |

### build_race_features() additions

- 13 rl_* columns: rl_log_odds_entropy, rl_odds_dispersion, rl_top3_odds_gap, rl_top1_odds, rl_favorite_rank_gap, rl_n_horses, rl_favorite_in_wide_top1, rl_trio_overlap, rl_market_consistency, rl_trio_odds_ratio, rl_wide_harville_ratio, implied_prob_hhi, odds_skewness
- 5 phase36_* aggregates

### _build_race_level_features() additions

- 5 phase36_* aggregates computed from feat_df via groupby("race_id")
- Same NaN-safe pattern as rl_* propagation

### BacktestEngine fix

- quality_score computed once via `self._race_predictor.get_quality_score(result_df)` before should_bet() branch
- Both quality_passed=True/False diagnostic branches now use actual score instead of 0.0
