    Create module with class EVTailCalibrator:
    1. FAMILY_FEATURES class constant: dict mapping family name to list of feature column names:
       - "trf": ["form_trend_race_rank", "blood_total_wr_race_rank", "blood_surface_wr_race_rank"]
       - "int": ["grade_x_form_trend", "distance_x_closing_index", "grade_x_blood_prize_log"]
       - "hlf": ["closing_speed_ratio_avg", "harontime_last3f_avg", "haron_race_gap_avg", "pace_ratio_avg"]
       - "market": ["implied_prob_hhi", "odds_skewness", "overround", "market_entropy"]
       - "ability": ["p_win_pred"]
    2. Constants: ZSCORE_THRESHOLD=1.0, SINGLE_FAMILY_FACTOR=0.85, MULTI_FAMILY_FACTOR=1.05, NO_FAMILY_FACTOR=0.70, EV_THRESHOLD=1.5

    Method `calibrate(self, horse_row: pd.Series, race_df: pd.DataFrame, ev_value: float) -> float`:
    1. If ev_value < EV_THRESHOLD: return ev_value unchanged
    2. For each family in FAMILY_FEATURES.values():
       a. Get available features from race_df columns (intersection)
       b. If no features available: skip family (does not count as agreeing)
       c. For each available feature in horse_row: compute z-score = (horse_value - race_mean) / race_std, handling std=0 by treating z=0
       d. Family agrees if ANY feature z-score > ZSCORE_THRESHOLD
    3. Count agreeing families
    4. Apply: 0 → NO_FAMILY_FACTOR, 1 → SINGLE_FAMILY_FACTOR, 2+ → MULTI_FAMILY_FACTOR
    5. Return ev_value * factor
