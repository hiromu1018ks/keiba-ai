# Phase 36.1.1 Plan 03: EV Tail Calibration Summary

EV >= 1.5 の高EV長穴候補を 5 つの feature family 合意度でスケーリングする EVTtailCalibrator を実装し、race_predictor.py の get_win_candidates() に統合。

## What Changed

### src/betting/ev_tail_calibration.py (new)

EVTtailCalibrator class:

1. **FAMILY_FEATURES** -- 5 family の特徴量カラム定義:
   - TRF: form_trend_race_rank, blood_total_wr_race_rank, blood_surface_wr_race_rank
   - INT: grade_x_form_trend, distance_x_closing_index, grade_x_blood_prize_log
   - HLF: closing_speed_ratio_avg, harontime_last3f_avg, haron_race_gap_avg, pace_ratio_avg
   - Market: implied_prob_hhi, odds_skewness, overround, market_entropy
   - Ability: p_win_pred

2. **calibrate(horse_row, race_df, ev_value)** method:
   - EV < 1.5: passthrough (no scaling)
   - Per-family z-score computation (horse_value - race_mean) / race_std
   - std=0 handling: z=0 (no agreement)
   - Missing columns: family skipped (does not count)
   - 0 families: 0.70x / 1 family: 0.85x / 2+ families: 1.05x

### src/backtest/race_predictor.py (modified)

get_win_candidates() integration:
- After basic mask filter, iterate candidates with edge >= 1.5
- Apply EVTtailCalibrator.calibrate() for each high-EV candidate
- Sort by _calibrated_edge instead of raw edge_col
- Drop _calibrated_edge before returning (internal only)
- Original win_selection_edge preserved for diagnostic logging

### tests/test_ev_tail_calibration.py (new)

20 tests across 8 test classes:
- TestPassthrough (3): EV below/at threshold, negative EV
- TestZeroFamilyAgreement (1): all features near mean
- TestSingleFamilyAgreement (2): TRF only, Market only
- TestMultiFamilyAgreement (3): 2, 3, all families
- TestMissingColumns (2): all missing, partial missing
- TestStdZero (1): identical values
- TestConstants (5): family count, factor values, feature names
- TestGetWinCandidatesIntegration (3): low EV passthrough, high EV calibration, no internal column leak
