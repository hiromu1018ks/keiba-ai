  <action>
    Create `scripts/diagnose_phase36_diff.py` as a CLI script with the following functions:

    **load_backtest_results(path: str) -> pd.DataFrame**
    - Read CSV file, standardize column names to lowercase
    - Ensure race_id, umaban columns exist
    - Filter to win bets only (if bet_type column exists)
    - Return DataFrame

    **find_common_races(baseline_df: pd.DataFrame, current_df: pd.DataFrame) -> tuple[set, set, set]**
    - Return (common_race_ids, baseline_only_race_ids, current_only_race_ids) as sets of strings
    - Uses set intersection/difference on race_id columns

    **compute_horse_overlap(baseline_df: pd.DataFrame, current_df: pd.DataFrame, common_race_ids: set) -> dict**
    - For each common race, identify: same_horse (voted in both), baseline_only (voted only in baseline), current_only (voted only in current)
    - Return dict with counts and DataFrames for each category
    - Uses merge on (race_id, umaban) with indicator=True

    **compute_roi_breakdown(df: pd.DataFrame) -> dict**
    - Given a bet DataFrame, compute: n_bets, total_stake, total_return, roi (total_return / total_stake), win_rate
    - Handle empty DataFrame (return zeros)

    **generate_report(baseline_path: str, current_path: str) -> dict**
    - Load both CSVs, find common races, compute horse overlap, compute ROI for each group
    - Return dict with keys: n_common_races, n_baseline_only_races, n_current_only_races, same_horse (roi breakdown), baseline_only_horse (roi breakdown), current_only_horse (roi breakdown)

    **Phase36 Contribution Decomposition (phase36_contribution key in report):**
    The report includes a  sub-dict that isolates Phase36-specific impact:
    1. Compute ROI for same_horse group in common races (ROI_same) -- this is the baseline ROI shared by both versions
    2. Compute ROI for current_only_horse group in common races (ROI_new) -- these are bets added/changed by Phase36.1.1 fixes
    3. Compute ROI for baseline_only_horse group in common races (ROI_removed) -- these are bets removed by Phase36.1.1 fixes
    4. Phase36 net contribution = (ROI_new * stake_new - ROI_removed * stake_removed) / total_stake_common
    5. Sub-keys: roi_same, roi_new, roi_removed, n_new_horses, n_removed_horses, net_contribution_pct
    6. Additionally compute market_model_only_bets: races where quality_passed changed from False (baseline) to True (current), indicating RaceQualityScreener fix effect
    7. And ev_tail_bets: in current_only_horse group, bets where EV >= 1.5 indicating EVTailCalibrator effect

    **main() CLI entry point**
    - argparse with --baseline and --current (required paths to CSV files)
    - --output optional path for JSON report
    - Print summary to stdout
    - Write JSON report if --output specified

    Create `tests/test_diagnose_phase36_diff.py` with unit tests for each function using small synthetic DataFrames (3-4 races, 2-3 bets each). Use pytest fixtures for test data.
