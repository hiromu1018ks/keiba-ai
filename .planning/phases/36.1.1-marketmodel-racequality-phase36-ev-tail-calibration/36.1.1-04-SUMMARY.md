# Phase 36.1.1 Plan 04: v1.7 vs Current Backtest Diff Diagnostic Summary

v1.7 baseline と現行 backtest 結果の共通レース同馬/別馬差分と Phase36 寄与分解レポートを生成する診断スクリプト。

## What Was Built

### scripts/diagnose_phase36_diff.py

CLI診断スクリプト (6関数):

1. **load_backtest_results(path)** -- CSV読み込み、列名小文字化、win bet フィルタリング
2. **find_common_races(base_df, curr_df)** -- race_id 集合の積集合/差分を返す
3. **compute_horse_overlap(base_df, curr_df, common_ids)** -- merge with indicator=True で同馬/別馬分類
4. **compute_roi_breakdown(df)** -- n_bets, total_stake, total_return, roi, win_rate を計算 (空DF対応)
5. **generate_report(baseline_path, current_path)** -- 全レポート生成 + phase36_contribution sub-dict
6. **main()** -- argparse CLI (--baseline, --current, --output)

Phase36寄与分解レポート:
- roi_same / roi_new / roi_removed
- n_new_horses / n_removed_horses
- net_contribution_pct = (roi_new * stake_new - roi_removed * stake_removed) / total_stake
- screener_fix_count: quality_passed False->True のレース数
- ev_tail_count: current_only で EV>=1.5 のベット数
