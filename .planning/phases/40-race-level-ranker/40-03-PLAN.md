    The insertion point is right after the MAWC else/fallback block ends. Add:

    ```
    # --- Race-Level Ranker (RNK-03, shadow mode per D-20/D-21) ---
    ranker = getattr(submodel, "win_race_level_ranker", None)
    if ranker is not None and ranker.is_trained:
        df = ranker.score(df)

        # D-18: Shadow diagnostics -- baseline vs ranker per-race comparison
        # Identify which horse baseline would select (by win_market_selection_score)
        # vs which horse ranker would select (by investment_score)
        if "win_market_selection_score" in df.columns and "investment_score" in df.columns:
            def _pick_selected(row_group: pd.DataFrame, score_col: str) -> int:
                """Return umaban of the horse with highest score in this race."""
                idx = row_group[score_col].idxmax()
                return row_group.loc[idx, "umaban"]

            race_groups = df.groupby("race_id", observed=True)
            baseline_picks = race_groups.apply(lambda g: _pick_selected(g, "win_market_selection_score"))
            ranker_picks = race_groups.apply(lambda g: _pick_selected(g, "investment_score"))

            # Map picks back to DataFrame as per-row diagnostic columns
            df["baseline_selected_umaban"] = df["race_id"].map(baseline_picks)
            df["ranker_selected_umaban"] = df["race_id"].map(ranker_picks)
            df["baseline_ranker_agreement"] = df["baseline_selected_umaban"] == df["ranker_selected_umaban"]
    ```

    This follows the EXACT getattr + is_trained pattern used by MAWC at lines 269-271. The ranker.score() method handles:
    - Shadow mode guard (returns df unchanged if not trained)
    - Scoring ALL runners (not restricted to gate-passed per D-20)
    - Adding diagnostic columns: relevance_score, value_score, relevance_score_pct, value_score_pct, calibrated_log_ev_pct, uncertainty_penalty_pct, investment_score (per D-05)

    The D-18 diagnostic block adds per-race comparison columns:
    - baseline_selected_umaban: umaban of the horse with highest win_market_selection_score in each race
    - ranker_selected_umaban: umaban of the horse with highest investment_score in each race
    - baseline_ranker_agreement: True/False whether both selectors picked the same horse

    These columns are diagnostic-only. They do NOT alter the baseline selection logic or the output of get_win_candidates(). The agreement rate can be computed from these columns in backtest reporting (Phase 41 Shadow Comparison Framework will build on these).

    No changes to get_win_candidates() in this phase. investment_score is added as a diagnostic column only. The baseline selection logic (win_market_selection_score sorting) is completely preserved per D-16/D-17.
