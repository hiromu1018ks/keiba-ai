    1. src/backtest/shadow_diagnosis.py を新規作成。以下を実装:

    データクラス:
    - ProbabilityQualityResult: baseline/shadow の Brier, logloss, ECE, actual_predicted_ratio, n_horses。Delta値(delta_brier, delta_logloss, delta_ece, delta_apr)も含む。
    - SelectionGroupMetrics: ROI, hit_rate, avg_odds, actual_predicted_ratio, bet_count, n_races。
    - SelectionPatternResult: changed (SelectionGroupMetrics), unchanged (SelectionGroupMetrics), n_changed_races, n_unchanged_races, delta_roi, delta_hit_rate。
    - SegmentCalibration: segment_name, segment_value, n_samples, actual_predicted_ratio_baseline, actual_predicted_ratio_shadow, ece_baseline, ece_shadow, delta_apr, delta_ece。
    - CalibrationResult: segments (list[SegmentCalibration]), grouped by segment_name (surface/odds_band/popularity_band/probability_rank_band/selected_changed)。
    - ShadowDiagnosisResult: step1 (ProbabilityQualityResult), step2 (SelectionPatternResult), step3 (CalibrationResult), missing_inputs (list[str]), variant_names (list[str]), generated_at (str)。

    セグメント定数 (per D-03):
    - POPULARITY_BAND_EDGES = [0, 3, 6, 9, 14, float("inf")]
    - POPULARITY_BAND_NAMES = ["1-3", "4-6", "7-9", "10-14", "15+"]
    - PROB_RANK_BAND_EDGES = [0, 1, 3, 6, float("inf")]
    - PROB_RANK_BAND_NAMES = ["top1", "2-3", "4-6", "7+"]
    - ODDS_BAND_EDGES = [0, 3, 5, 10, 30, float("inf")] (Phase 41 既存)
    - ODDS_BAND_NAMES = ["1-3", "3-5", "5-10", "10-30", "30+"]

    ShadowDiagnosis クラス:
    - __init__(input_dir: Path): Phase 41 成果物を読み込み。self.race_diff, self.horse_diff, self.result_json, self.manifest, self.missing_inputs を初期化。manifest["variants"] または manifest["folds"] から variant 名を動的に取得して self.variant_names に格納 (per RESEARCH Pitfall 5)。baseline_name = variant_names[0], shadow_name = variant_names[1] とする。
    - run() -> ShadowDiagnosisResult: 3ステップを実行して ShadowDiagnosisResult を返す。

    _step1_probability_quality() メソッド:
    - horse_diff 全行を対象。baseline_p_col = f"{baseline_name}_p_win_final", shadow_p_col = f"{shadow_name}_p_win_final"。
    - p_vals と kakuteijyuni==1 から Brier/logloss/ECE/actual_predicted_ratio を各variantについて計算。
    - Brier計算: np.mean((p_valid - y_valid)**2)。logloss: -np.mean(y*log(p) + (1-y)*log(1-p))。ECE: ShadowComparisonFramework._compute_ece(p, y, n_bins=10)。actual_predicted_ratio: mean(y)/mean(p)。
    - Delta値: shadow - baseline。

    _step2_selection_pattern() メソッド:
    - race_diff の selected_changed 列でグループ化。group_race_ids = set(race_diff[race_diff.selected_changed == val]["race_id"])。
    - 各グループで race_diff の baseline_result / shadow_result から ROI/的中率/avg_odds を計算。race_diff の baseline_stake/shadow_stake, baseline_tanodds/shadow_tanodds 列を使用。
    - actual_predicted_ratio は horse_diff を group_race_ids でフィルタして計算。
    - Delta値: changed - unchanged。

    _step3_calibration_by_segment() メソッド:
    - horse_diff にセグメント列を追加:
      - popularity_band: horse_diff に "popularity" 列があれば pd.cut(popularity, POPULARITY_BAND_EDGES, POPULARITY_BAND_NAMES)。無ければ missing_inputs に "popularity" を追加してスキップ。
      - probability_rank_band: レース内で baseline_p_win_final の降順ランクを計算 (groupby race_id で rank)。そのランクを pd.cut(prob_rank, PROB_RANK_BAND_EDGES, PROB_RANK_BAND_NAMES) に割り当て。これは常に計算可能 (p_win_final は horse_diff に必ず存在)。
      - odds_band: horse_diff に "closing_win_odds" 列があれば pd.cut(closing_win_odds, ODDS_BAND_EDGES, ODDS_BAND_NAMES)。無ければ race_diff から baseline_tanodds をマージして計算を試み、それも無ければ missing_inputs に "closing_win_odds" を追加してスキップ。
      - surface: horse_diff に "surface" 列があればそのまま。無ければ race_diff に "surface" があれば race_id でマージ。どちらも無ければ missing_inputs に "surface" を追加してスキップ。
      - selected_changed: race_diff から race_id でマージ。
    - 各セグメント列について groupby でグループ化し、各グループで baseline/shadow の actual/predicted 比率と ECE を計算。SegmentCalibration を生成。
    - 欠損や空セグメントはスキップ (D-03 の unknown フォールバックではなく、空グループは出力しない。不明値は "unknown" ラベルとして扱う)。

    _detect_missing_inputs() メソッド:
    - 初期化時に horse_diff/race_diff の列をチェック。DIAG-03 で必要な列 (popularity, surface, tanodds, closing_win_odds) が不在なら self.missing_inputs に追加。

    2. tests/test_shadow_diagnosis.py を新規作成。テストヘルパー:
    - _make_horse_df(): 合成 horse_diff DataFrame を生成。列: race_id, umaban, kakuteijyuni, baseline_p_win_final, {shadow_name}_p_win_final, baseline_investment_score, baseline_stake, baseline_selected。必要に応じて popularity, surface, tanodds 列も追加/省略。
    - _make_race_df(): 合成 race_diff DataFrame を生成。列: race_id, baseline_selected_umaban, shadow_selected_umaban, selected_changed, baseline_result, shadow_result, baseline_stake, shadow_stake, baseline_tanodds, shadow_tanodds。
    - _make_manifest(): 合成 manifest JSON (variants に baseline + shadow_name を含む)。
    - _setup_input_dir(tmp_path, ...): input_dir に JSON/Parquet ファイルを書き出すヘルパー。
    - test_run_returns_result: 疎通テスト。
    - test_step1_probability_quality: Brier/logloss/ECE 値を数値検証。
    - test_step2_selection_pattern: changed/unchanged グループの ROI/HR を検証。
    - test_step3_calibration: セグメント別 actual/predicted 比率を検証。
    - test_missing_inputs_detection: popularity 列を省略して missing_inputs に "popularity" が含まれることを検証。
    - test_segment_fallback_empty_group: 小規模データで空セグメントがスキップされることを検証。
    - test_variant_name_from_manifest: manifest の variant 情報から列名プレフィックスが正しく解決されることを検証。
