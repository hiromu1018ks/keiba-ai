Per D-02, implement 4 sequential analysis steps in strict order:

**Step 1 — attribute_ece_degradation():**
- Load shadow_horse_diff.parquet. For each horse, compute p_win delta = ridge_shadow_p_win_final - baseline_p_win_final. This is the MAWC + race normalization effect (Ranker does not modify p_win, only adds investment_score).

- Per segment: compute (a) ECE with baseline p_win, (b) ECE with shadow p_win, (c) delta ECE, (d) mean p_win shift, (e) actual_predicted_ratio with baseline vs shadow p_win.
- Determine attribution: if ECE worsens in a segment AND p_win shift is significant, attribute to MAWC direct effect. If ECE worsens only in selected subpopulation, attribute to selection population effect.
- Key finding from Phase 43: odds_band 1-3 shadow ECE=0.1444 vs baseline=0.0447 (3x worse). MAWC beta_market_contribution=0.90 suggests logit(p_market) over-weighting.

**Step 2 — attribute_apr_deviation():**
- Compute APR = actual_predicted_ratio for all-horse baseline vs all-horse shadow (Phase 43 step1 data: baseline APR=0.928, shadow APR=1.154).
- Compute APR for selected-horses only (baseline_selected vs ridge_shadow_selected subpopulations).
- If all-horse APR deviation is large AND selected-only APR is closer to 1.0, attribute APR to MAWC probability level issue. If selected-only APR deviates more, attribute to Ranker selection bias.
- Key data: shadow overall APR=1.15 (over-prediction), baseline=0.93 (under-prediction). ideal=1.0.

**Step 3 — attribute_bet_count_loss():**
- Total bet_count gap: baseline ~3327 vs shadow ~2580 for 2024 (per gate result).
- Decompose: (a) races where selection changed (selected_changed=True) — count baseline_selected vs ridge_shadow_selected, quantify Ranker-driven exclusions. (b) For unchanged races, compare OBF pass-through rates if data available (from shadow_race_diff: stake>0 filtering).
- Per D-04, integrate OddsBandFilter analysis here. Compare excluded_bands and pass rates between baseline and shadow variants. training_bet_history ROI overstatement is documented as in-sample calibration risk but not causally linked without ablation.
- Key data from Phase 43: changed_shadow bet_count=706 vs changed_baseline bet_count=2123. Ranker reduces 2123 to 706 in changed races (67% reduction).

**Step 4 — Coefficient analysis (BISECT-02 per D-03):**

analyze_mawc_coefficients():
- Load data/models-backtest/{2024,2025}/market_aware_win_calibrator_{turf,dirt}.joblib via joblib.load.
- Extract state["calibrator"].coef_[0] (shape 51,) and state["feature_names"].
- For each feature: compute absolute coefficient value and identify dominant terms.
- Focus: logit_market (idx 1, coef~0.39), logit_model (idx 0, coef~0.04), log_odds (idx 2, coef~-0.36), and their interaction terms with segments.
- Compute per-segment effective contribution = coef[main] + sum(coef[interaction_with_main * segment_indicator]).
- Identify segments where MAWC over-corrects: odds_band 1-3 (ECE 3x), popularity 10-14 (APR 2.3x), probability_rank top1.

analyze_ranker_coefficients():
- Load data/models-backtest/{2024,2025}/win_race_level_ranker_turf.joblib. Ranker is turf-only (per RESEARCH Pitfall 3).
- Extract state["relevance_scorer_turf"].coef_ (shape ~15,) with relevance_feature_names.
- Extract state["value_scorer_turf"].coef_ (shape ~15,) with value_feature_names.
- Identify which features dominate: if_p_win_final (rel weight ~0.80), if_ev_calibrated (val weight ~0.83), if_overround (val weight ~-0.74).
- Assess bias: if investment_score heavily weights p_win_final, ranker favors favorites in a way that may reduce bet_count.

analyze_segment_coefficient_contribution():
- Split horse_diff into 3 groups: (a) changed races where shadow selected different horse (selected_changed=True in race_diff), (b) dropped races where baseline had bet but shadow does not (baseline_selected=True AND ridge_shadow_selected=False), (c) retained races where both select same horse.
- For each group: compute MAWC effective contribution (p_win delta distribution), Ranker effective contribution (investment_score distribution), and compare.
- This shows whether dropped/changed races have systematically different coefficient impact.
