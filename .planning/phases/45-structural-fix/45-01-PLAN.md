Method `prepare_oof_data(oof_path: Path) -> tuple[pd.DataFrame, pd.DataFrame]`:
- Load oof_predictions.parquet
- Derive p_model = p_win_corrected column (per RESEARCH RQ-1: p_win_corrected is semantically equivalent to p_win_oof for MAWC training)
- Derive p_market = np.clip(1.0 / df["tanodds"].values, 0.01, 0.99) (identical to MAWC inference path per CONTEXT code_context)
- Derive p_win_race_rank_pct = df.groupby("race_id", observed=True)["p_model"].rank(pct=True, method="min", ascending=False) (per RESEARCH RQ-1 derivation)
- Derive popularity_rank_pct = popularity_rank / max(field_size, 1) (per MAWC build_feature_matrix pattern)
- Filter rows: dropna on required columns (p_model, p_market, tanodds, popularity_rank, field_size, kakuteijyuni, race_id, surface)
- Split into turf_df and dirt_df by surface column
- Return (turf_df, dirt_df)

Method `build_conservative_feature_matrix(df: pd.DataFrame) -> tuple[np.ndarray, list[str]]`:
- Reuse MarketAwareWinCalibrator's encoding helpers by instantiating a temporary MAWC and calling its _encode_odds_band, _encode_pop_bucket, _encode_p_rank methods
- Build main effects (6): logit_model, logit_market, log_odds, popularity_rank_pct, p_win_race_rank_pct, field_size -- identical to original MAWC
- Build segment one-hot (15): 7 odds_band + 5 pop_bucket + 3 p_rank -- identical to original MAWC
- Build logit_market x segment interactions (15): logit_market[:, None] * segment_features -- KEPT per D-02
- DO NOT build logit_model x segment interactions (15) -- REMOVED per D-02
- Assemble: 6 + 15 + 15 = 36 features (not 51)
- Assert len(feature_names) == 36 and X.shape[1] == 36
- Return (X, feature_names)

Method `retrain_with_c_grid(df: pd.DataFrame, baseline_mawc: MarketAwareWinCalibrator) -> list[CGridCandidateResult]`:
- Build conservative feature matrix from df
- Extract y = (df["kakuteijyuni"] == 1).astype(int).values
- Load baseline MAWC quality metrics (Brier, logloss, ECE) by applying baseline_mawc to df (or computing from baseline_mawc predictions)
- For each C in CONSERVATIVE_C_GRID:
  - Fit LogisticRegression(C=c, max_iter=1000, fit_intercept=True) on full X, y
  - Create a new MarketAwareWinCalibrator instance, set its calibrator, feature_names (36-dim), best_c=c
  - Compute predictions: p_conservative = lr.predict_proba(X)[:, 1]
  - Compute overall Brier/logloss/ECE on full OOF
  - Call evaluate_quality_gates() with baseline metrics and conservative predictions
  - Create CGridCandidateResult
- Return all candidates sorted by C (ascending)

Method `evaluate_quality_gates(y: np.ndarray, p_conservative: np.ndarray, p_baseline: np.ndarray, df: pd.DataFrame, baseline_brier: float, baseline_logloss: float, baseline_ece: float) -> QualityGateResult`:
- Compute overall Brier/logloss/ECE for conservative predictions using sklearn.metrics.brier_score_loss, log_loss, and a local _compute_ece function (reuse the ECE algorithm from ShadowComparisonFramework._compute_ece -- 10-bin ECE computation)
- Check non-degradation: conservative metric <= baseline * (1 + ECE_DEGRADATION_TOLERANCE) for each metric
- Compute favorite band guard (D-04):
  - Filter df to odds 1-3 band (tanodds >= 0 and tanodds < 3)
  - For this subset: compute ECE with conservative vs baseline predictions
  - Compute p_compression_ratio = mean(p_conservative / max(p_baseline, 1e-10)) for odds 1-3 -- must be >= P_COMPRESSION_FLOOR (0.90)
  - Compute ev_pass_rate: pct where p * tanodds >= 1.0 for both baseline and conservative
  - ev_pass_rate check: conservative pass rate >= baseline pass rate * (1 - BET_COUNT_TOLERANCE)
- Check year-level non-degradation: if race_date available, compute per-year Brier/logloss/ECE and verify each year is within tolerance
- Create FavoriteBandGuardResult and QualityGateResult

Method `select_best_c(candidates: list[CGridCandidateResult]) -> CGridCandidateResult | None`:
- Filter to candidates where quality_gate.all_gates_passed is True
- If no candidates pass: return None (not_deployed per D-04 item 6)
- Among passing candidates: return the one with minimum C value (strongest regularization, per D-04 item 5)

Method `run_retrain(surface: str, df: pd.DataFrame, baseline_mawc_path: Path) -> ConservativeRetrainResult`:
- Load baseline MAWC from baseline_mawc_path using MarketAwareWinCalibrator.load()
- Run retrain_with_c_grid(df, baseline_mawc)
- Call select_best_c() on candidates
- If best is None: set deployed=False, manifest includes "not_deployed" status
- If best found: set deployed=True
- Build manifest_metadata dict with: surface, best_c, n_candidates, n_passing, deployed status, removed_interactions list, feature_dim=36
- Return ConservativeRetrainResult

**ECE computation:** Implement a module-level `_compute_ece(y_pred: np.ndarray, y_true: np.ndarray, n_bins: int = 10) -> float` function following the exact algorithm from ShadowComparisonFramework._compute_ece. Do NOT import from shadow_comparison (avoids circular dependency risk and keeps the module self-contained for OOF evaluation).

**Baseline metrics computation:** When a baseline MAWC is loaded, apply its build_feature_matrix to the same df (which will produce 51-dim features for the baseline), get baseline predictions, and compute Brier/logloss/ECE. This provides the "before" metrics for non-degradation comparison.
