Constants:

Method `_should_run(output_path: Path, force: bool) -> bool`:
- If force=True: return True
- If output_path.exists(): log "SKIP: {path} already exists" and return False
- Else: return True

Method `_check_manifest_deployed(manifest_path: Path) -> bool`:
- Load manifest.json from manifest_path
- Iterate per_year_surface dict values, then each surface dict
- Return True if ANY surface has deployed=true
- Return False if no surfaces deployed (log error and return False)

Method `_run_stage1(args) -> Path`:
- manifest_path = args.conservative_root / "manifest.json"
- If not _should_run(manifest_path, args.force): log "Stage 1 SKIP" and return manifest_path
- Invoke subprocess: [sys.executable, "scripts/run_mawc_conservative_retrain.py", "--oof-path", str(args.oof_path), "--source-model-dir", str(args.source_model_dir), "--target-root", str(args.conservative_root), "--years", args.years]
- If --report flag set, add "--report" to subprocess args
- capture_output=True, text=True, cwd=ROOT
- If returncode != 0: log stderr, record stage1=FAIL, sys.exit(1)
- Verify manifest_path exists after execution
- Verify _check_manifest_deployed(manifest_path) -- if False, log "No surfaces deployed in conservative variant", record stage1_status="FAIL_NO_DEPLOYED", write partial result, sys.exit(1)
- Return manifest_path

Method `_run_oof_validation(args) -> dict`:

- cmd = [sys.executable, "scripts/run_shadow_comparison.py", "--baseline-root", str(args.source_model_dir), "--shadow-root", str(args.conservative_root), "--folds"] + args.years.split(",") + ["--output-dir", str(output_dir), "--baseline-name", "baseline", "--shadow-name", "mawc_conservative"]

Method `_run_deployment_gates(args) -> dict`:
- result_path = str(args.shadow_output_dir / "shadow_comparison_result.json")

Method `_compute_roi_trend(shadow_result: dict) -> str`:
- Extract shadow ROI from shadow_result["overall"]["metrics"]["shadow"]["roi"] (navigate shadow_comparison_result.json structure)
- If shadow_roi >= RECOVERED_THRESHOLD: return "recovered"
- If shadow_roi >= BASELINE_ROI_THRESHOLD: return "weak_recovery"
- Return "not_recovered"
- If ROI extraction fails (KeyError, nested dict missing): return "unknown" with warning log

Method `_compute_deployment_verdict(quality_gate: str, roi_trend: str) -> str`:
- If quality_gate == "FAIL": return "not_deployable"
- If roi_trend == "recovered": return "deployable"
- If roi_trend == "weak_recovery": return "deployable"
- If roi_trend == "not_recovered": return "manual_review"
- Return "manual_review"

  - artifacts: dict of artifact_name -> file_path for all produced files
