    Create src/features/horse_track_aptitude.py with function precompute_track_aptitude(entries_df, races_df, track_conditions_df) -> pd.DataFrame.

    Per D-01: Use expanding window + shift(1) pattern from horse_career_stats.py. Each (kettonum, race_id) row reflects only past race results.

    Per D-02: Output keyed on race_id + kettonum. This is the merge key for FeatureEngine.build_all().

    Per D-03: Condition thresholds default to dirt_wet >= 12%, dirt_dry < 3%, turf_hard >= 10, turf_soft < 8. These match Phase 48 dirt_moisture_high_flag/dry_flag and D-12 bin boundaries.

    Per D-04: Hit definition: kakuteijyuni <= 3 (top 3 finish). Exclusions: kakuteijyuni <= 0 or NaN excluded from denominator.

    Per D-05: horse_condition_type classification with min_starts=3, hit_rate_threshold=0.3. Categories: wet_good, dry_good, balanced, unknown. When denominator (wet_starts or dry_starts) < min_starts, that condition's aptitude is NaN -> cannot classify -> unknown.

    Per D-06: horse_condition_versatility = mean(wet_hit_rate, dry_hit_rate) * (1 - |wet_hit_rate - dry_hit_rate|). NaN when either component rate is NaN.

    Per D-07: Output schema has 14 columns total: 2 keys (race_id, kettonum), 4 hit rates, 4 starts counts, 1 versatility, 1 category (string), 2 prev values (prev_dirt_moisture, prev_turf_cushion).

    Implementation approach:
    1. Merge entries_df with races_df to get trackcd, then merge with track_conditions_df to get dirt_moisture/turf_cushion per race
    2. Sort by kettonum + race_date
    3. For each kettonum group, classify each past race's condition (wet/dry for dirt via moisture thresholds, hard/soft for turf via cushion thresholds)
    4. Use shift(1) + cumsum expanding pattern for PIT-safe counts (starts and hits)
    5. Compute hit_rate = cumulative_hits / cumulative_starts where starts > 0, else NaN
    6. Classify horse_condition_type per D-05 thresholds
    7. Compute horse_condition_versatility per D-06
    8. Extract prev_dirt_moisture/prev_turf_cushion via shift(1) on the sorted group

    Define APTITUDE_COLS list constant with all 14 column names.
