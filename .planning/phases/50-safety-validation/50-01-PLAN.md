    - --features-path: path to horse_features.parquet (default: data/features/horse_features.parquet)

    Per D-10: Compute NaN rates with surface-aware denominator. For each track condition feature:
    - dirt_* features: denominator = count of dirt rows only (surface == "dirt")
    - turf_* features: denominator = count of turf rows only (surface == "turf")
    - cross-surface features (track_front_bias_score, etc.): denominator = all rows

    Per D-11: Apply 3-tier threshold:
    - NaN rate < 30%: PASS
    - 30% <= NaN rate < 50%: WARN
    - NaN rate >= 50%: FAIL

    Per D-12: NaN cause separation report. For each feature with NaN > 0:
    - raw_cause_pct: fraction of NaN attributable to raw data missing (turf_cushion NaN or dirt_moisture NaN in source)
    - derived_cause_pct: fraction of NaN from derived processing (track_month_stats missing, insufficient data for zscore, etc.)
    - Computed by cross-referencing: if raw column (dirt_moisture/turf_cushion) is NaN and derived feature is also NaN -> raw_cause. If raw column is NOT NaN but derived is NaN -> derived_cause.

    Per D-13: WARN results are logged only, no action. FAIL triggers a detailed cause report.

    Per D-14: Training start date is NOT modified (report only).

    Output JSON structure:
    {
      "fold0_period": {"start": "...", "end": "..."},
      "total_rows": N,
      "turf_rows": N,
      "dirt_rows": N,
      "features": {
        "feature_name": {
          "nan_count": N,
          "denominator": N,
          "nan_rate": 0.XX,
          "verdict": "PASS|WARN|FAIL",
          "cause_separation": {"raw_cause_pct": 0.XX, "derived_cause_pct": 0.XX}
        }
      },
      "overall_verdict": "PASS|WARN|FAIL"
    }
