       - Stores SHA256 of `feature_manifest.compute_hash()` as `self._manifest_hash`

    Create `src/features/session_manifest.py` per D-06, D-09:

    **get_code_version() -> dict** function per D-06:
    - Uses `subprocess.run(["git", "rev-parse", "HEAD"])` to get commit SHA
    - Uses `subprocess.run(["git", "status", "--porcelain", "--", "src/", "scripts/", "config/"])` to detect dirty state
    - Returns `{"commit_sha": str, "git_dirty": bool, "dirty_diff_hash": str | None}`
    - If dirty, computes SHA256 of `subprocess.run(["git", "diff", "src/", "scripts/", "config/"])` output
    - Also checks for untracked files in src/, scripts/, config/ — records in `untracked_files: list[str]`
    - Raises RuntimeError if git is not available or not in a git repo

    **SessionManifest** class per D-09:
    - Constructor `__init__(self, session_id: str, prediction_date: str)`:
       - Stores session_id (UUID4), prediction_date
       - Initializes empty fields for code_version, manifest_hash, model_run_id, training_period, pfp_result, status
    - Method `set_code_version(version: dict)`: Records git SHA and dirty state
    - Method `set_model_identity(run_id: str, training_start: str, training_end: str, manifest_hash: str)`: Records MLflow run ID, training period, feature manifest hash
    - Method `set_pfp_result(result: dict)`: Records PFP verification result
    - Method `set_status(status: str, exit_code: int = 0)`: Records completion status and exit code
    - Method `to_dict() -> dict`: Returns complete manifest as serializable dict
    - Property `is_dirty() -> bool`: Returns code_version["git_dirty"]

    **write_session_manifest(manifest: SessionManifest, path: Path)** per D-09:
    - Atomic write: write to temp file, then rename to target path
    - Uses `json.dumps(manifest.to_dict(), indent=2, default=str)`
    - Atomic via tempfile.NamedTemporaryFile + os.replace

    **Integration into run_paper_trading.py** `_run_predict()`:

    Add verification at three points per D-08:

    1. **PT startup** (before any prediction):
       - Call `get_code_version()` → if dirty, exit with non-zero unless `--allow-dirty` flag
       - Create `DataCutoffManifest.from_config(prediction_date, models, strategy_manifest_path)`
       - Call `cutoff_manifest.verify_strict(actual_dates)` — fail-fast if any data source exceeds prediction_date
       - Create `PFPVerifier(models, feature_manifest, feature_state, betting_target, betting_mode)`
       - Call `pfp_verifier.freeze()` — snapshot all parameters
       - Create `SessionManifest(session_id, prediction_date)` and populate all identity fields
       - Write session_manifest.json (atomic)

    2. **Pre-race prediction** (before each race):
       - Call `pfp_verifier.verify()` — if failed, stop predictions, save state, exit non-zero

    3. **PT end** (after all predictions):
       - Call `pfp_verifier.verify()` again — final immutability check
       - Record result in SessionManifest
       - Write final session_manifest.json

    Add `--allow-dirty` CLI flag to `run_paper_trading.py`:
    - When not set (default): dirty git state causes non-zero exit
    - When set: warning logged but execution continues
    - Parse in argparse section of main()
