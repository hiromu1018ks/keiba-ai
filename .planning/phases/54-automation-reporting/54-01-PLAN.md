    Create `src/paper_trading/report_aggregator.py` with PaperTradingReportAggregator class.

    Constructor takes `bets_path: Path`, `output_dir: Path`, `session_manifest: Any | None = None`.
    The `session_manifest` parameter provides model identity fields (model_run_id, training_start, training_end, manifest_hash) for RPT-04 per D-19.

    _load_bets() reads bets.parquet from bets_path. Validates schema using same pattern as PaperReconciler._validate_bet_schema (reject old v1 schema with "result" column). Returns DataFrame or empty DataFrame.

    _base_stats(bets_df) computes: total_bets, n_won, n_lost, n_pending, n_refunded, n_voided, effective_stake (won+lost only, D-05), total_return (payout sum of won+lost), roi=total_return/effective_stake, hit_rate=n_won/decidable_count. Returns dict.

    aggregate_daily(target_date: date) filters bets by race_date == target_date. Computes _base_stats plus pending_count, unsettled_stake (sum of stake where settlement_status=="pending"), data_completeness (string: "complete" if 0 pending, "partial" if some pending, "no_data" if empty). Adds model_identity dict from session_manifest if available. Returns dict with common fields (schema_version="2.0", period=str(target_date), generated_at=now ISO, session_ids=[...]).

    aggregate_weekly(iso_year: int, iso_week: int) computes date range using _iso_week_range helper (Jan 4 based calculation per RESEARCH.md). Filters bets by race_date in [week_start, week_end]. Calls _base_stats. Returns dict with common fields, period formatted as "YYYY-WNN".

    aggregate_by_target(target_date: date | None = None) groups bets by bet_type column. For each group (win/place), computes _base_stats. Returns dict with per-target breakdown and common fields.

    aggregate_all(target_date: date) calls all three aggregation methods. Returns dict with "daily", "weekly", "target" keys.

    save_outputs(target_date: date) calls aggregate_all, then writes JSON files per D-13:
    - daily_summary/YYYY/YYYY-MM-DD.json (year subdirectory, not flat)
    - weekly_summary/{iso_year}/W{iso_week:02d}.json
    - target_summary/YYYY-MM-DD.json
    - target_summary/latest.json (copy of current target summary)
    All JSON writes use _atomic_write_json helper (tempfile.mkstemp + os.replace pattern from session_manifest.py).

    _iso_week_range(iso_year, iso_week) returns tuple[date, date] for Monday-Sunday of the ISO week. Uses date(iso_year, 1, 4) - timedelta(days=weekday) pattern.

    Create `tests/test_report_aggregator.py` with 10 tests using mock DataFrames and temp directories.
