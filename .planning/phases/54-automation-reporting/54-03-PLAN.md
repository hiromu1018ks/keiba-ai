<objective>
Shrink PaperTradingReport to a pure HTML renderer that consumes PaperTradingReportAggregator results, removing all aggregation logic from the report class (D-12).

Purpose: The report class currently computes its own stats (_derive_fields, _compute_monthly_stats) using the old v1 `result` column. By switching it to consume Aggregator results, we eliminate the old schema dependency and ensure HTML/JSON share identical statistics (D-11). The report reads bet data for the history table from bets.parquet directly -- no intermediate JSON/CSV row duplication (D-10).

Output: PaperTradingReport.generate() takes Aggregator output dict, renders HTML with new schema fields. Old aggregation methods removed. Tests pass.
</objective>
