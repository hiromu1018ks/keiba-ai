# 競馬の基礎知識

このドキュメントでは、AI予測システムを理解するために必要な競馬の基礎知識を解説します。
競馬をまったく知らない方でも読めるよう、なるべくわかりやすく書いています。

---

## 馬券とは

馬券（ばけん）とは、レースの結果を予想して買う「予想チケット」のことです。
当たれば払戻し（はらいもどし）をもらえ、外れれば買った金額はそのまま没収されます。

私たちのシステムが予測対象としているのは、以下の3種類の馬券です。

### 単勝（たんしょう）

**1着になる馬を当てる**、最もシンプルな馬券です。

> 比喩: クラスのテストで「1番の人だけ当たり」のクイズを想像してください。
> 1番の人を当てれば正解ですが、2番以下はすべて不正解です。
> 当てるのは難しいですが、当たったときの返ってくる金額（オッズ）が大きくなりがちです。

### 複勝（ふくしょう）

**3着以内に入る馬を当てる**馬券です。単勝より当たりやすく、初心者におすすめです。

> 比喩: クラスのテストで「上位3人まで当たり」のクイズです。
> 1番でも2番でも3番でも正解なので、単勝よりはるかに当たりやすいです。
> そのぶん、返ってくる金額は少なめになります。

### ワイド

**2頭の馬を指定し、その2頭がどちらも3着以内に入るか**を当てる馬券です。

> 比喩: 「この2人は表彰台に上がるか？」を当てるクイズです。
> 指定した2頭のうち、どちらか1頭でも4着以下なら外れです。
> 両方とも3着以内なら当たり、となります。

---

## オッズとは

オッズとは、馬券の**「値段」**です。言い換えると、**その馬が1着になったときにいくら返ってくるか**を表す数字です。

### オッズの見方

オッズは「倍率」で表示されます。**100円分の馬券を買った場合**の返ってくる金額の目安です。

| オッズ | 100円買った場合の払戻し |
|--------|------------------------|
| 2.0    | 200円                  |
| 5.0    | 500円                  |
| 10.0   | 1,000円                |
| 50.0   | 5,000円                |

たとえばオッズ10.0の馬の単勝を100円買って1着になったら、100円 x 10.0 = 1,000円が返ってきます。
利益は 1,000 - 100 = 900円です。

### オッズは「確率」ではない

ここがとても重要です。オッズ10.0だから「10回に1回当たる（10%の確率）」とは限りません。

なぜなら、**オーバーラウンド**という仕組みがあるからです。

競馬では、全馬のオッズから計算される「理論上の確率の合計」が**100%を超えます**。
日本の競馬では、だいたい**約120%**になります。この超過分の**約20%**がJRA（主催者）の手数料として差し引かれます。

> 比喩: 100個のクッキーが入った箱を「全員で分けよう」と言われて手渡されます。
> でも開けてみると80個しかありません。残り20個はゲームの参加料として取られたのです。
> これがオーバーラウンドです。だから、オッズだけで「確率だ」と判断するのは危険です。

## 払戻しの計算

払戻しの計算はとてもシンプルです。

```
払戻し = 買った金額 x オッズ
```

例: オッズ5.0の複勝を300円買って3着以内に入った場合

```
300円 x 5.0 = 1,500円（払戻し）
利益 = 1,500円 - 300円 = 1,200円
```

馬券は**100円単位**で買います。200円、300円、500円……好きな金額を100円刻みで購入できます。
ただし、当たったときの払戻しも買った金額に比例して増えるだけなので、
「100円買って当たる確率」と「1000円買って当たる確率」は同じです。

## 人気と実力の違い

競馬では**「人気」と「実力」は別もの**です。

- **人気**: 多くの人が「この馬が勝ちそう」と思って買っている状態。オッズが低い馬のこと。
- **実力**: 過去のレース結果やタイムなど、データから測れる本当の強さ。

人気のある馬が必ずしも強いわけではありません。
有名な騎手が乗っていたり、前のレースで勝っていたりすると、
「強そう」と思われて人気が出ますが、それはあくまで**人々の印象**です。

> 比喩: 学校の人気投票とテストの成績は違いますよね。
> 人気投票では「性格がいい子」や「面白い子」が上位になりがちですが、
> テストの成績は勉強の成果です。
> 競馬の「人気」は人気投票のようなもので、
> このAIシステムが予測しているのは「テストの成績」のようなものです。

**AIは、人々の感情ではなく、データ（過去のレース成績、タイム、コース適性など）から「実力」を予測します。**
これが、人間の予想とAIの予測の最大の違いです。

## 用語集

| 用語 | 読み方 | 意味 |
|------|--------|------|
| **単勝** | たんしょう | 1着になる馬を当てる馬券 |
| **複勝** | ふくしょう | 3着以内に入る馬を当てる馬券 |
| **ワイド** | わいど | 指定した2頭がどちらも3着以内に入るかを当てる馬券 |
| **オッズ** | おっず | 馬券の「値段」。当たったときの返ってくる金額の倍率 |
| **人気** | にんき | 多くの人が買っている馬のこと。オッズが低い馬が人気馬 |
| **払戻し** | はらいもどし | 馬券が当たったときに返ってくる金額 |
| **回収率** | かいしゅうりつ | 使った金額のうち、何%が払戻しとして返ってきたかを表す指標。100%を超えれば利益 |
| **ドローダウン** | どろーだうん | 一時的に資金が減る幅のこと。「最大ドローダウン」は一番資金が減った時の金額 |
| **芝** | しば | 芝生のコース。スピードが出やすく、雨に弱い |
| **ダート** | だーと | 土のコース。スピードは落ちるが、雨に強い |
