## Ralph Loop Iteration Log (2026-04-18)

### Changes Made
1. **--skip-train option** (run_backtest.py): キャッシュ済みモデルをロードしてテストのみ実行。学習25分→テスト8分に短縮。
2. **BenterCombination.fit() bounds** → α上限0.4 → **reverted** (β/γの極端な補正で逆効果)
3. **Race-sum normalization** → p_place_combined を3.0に正規化 → **reverted** (edge消失でROI悪化)
4. **Wide bet expansion** (複数パターン) → 全て品質希釈でROI低下 → **reverted**

| Attempt | Bets | ROI | Profit | Note |
|---------|------|-----|--------|------|
